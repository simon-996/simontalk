## 2. 视觉定位与参考取舍

设计目标是“容易开始、能安心停顿、聊完看得懂”。面向日常英语交流，以成熟、友好的工具感为主，兼有轻量陪伴感。

| 借鉴方向 | 采用的内容 | 对应页面 |
| --- | --- | --- |
| 温和极简 | 浅灰绿背景、清楚文字、单一品牌强调色、适度留白 | 全局 |
| Material 组件体系 | 语义颜色、明确交互反馈、可复用控件与主题 | 导航、按钮、输入、列表、弹层 |
| 平台交互习惯 | 熟悉的开关、返回、文字编辑、焦点与系统权限交互 | 设置、确认、登录和权限 |
| 轻量伙伴 | 小型抽象形象，动作只解释对话状态 | 首页、通话、空态 |

产品与开源参考选用 Loora、Nia，以及 [Wonderous](https://github.com/gskinnerTeam/flutter-wonderous-app)：借鉴对话节奏、复盘组织和少量页面衔接，不引入它们各自的完整功能或依赖。Loora 和 Nia 的来源与证据边界见[调研记录](../research/2026-10-15-product-and-stack-review.md)。

| 页面 | 主要视觉重点 | 次级内容的处理 |
| --- | --- | --- |
| 练习主页 | 标题、当前难度和一个“开始自由聊天”主按钮 | 小伙伴形成辨识，少量话题置于主入口之后；上次练习作为次级回看入口 |
| 通话 | 伙伴、真实状态与明确控制区 | 字幕和辅助可展开；结束按钮有独立位置，减少装饰占位 |
| 复盘 | 一个下次建议，随后按条阅读原句、建议表达和解释 | 完整对话收起，每条重练动作靠近对应建议，不叠放成绩仪表 |
| 记录 | 日期、话题、时长、状态和重练标识形成可扫描列表 | 用留白与分隔组织，不为每次练习制作大型插画卡 |
| 我的 | 个人信息、练习偏好、显示辅助和用量分组 | 使用熟悉的列表与表单；未结算和不可用状态清楚表达 |

UI/UX Pro Max 已执行 `language learning voice companion calm` 的设计系统检索，并以 `adult speaking practice mobile` 缩小后重试。两次均返回营销页结构和儿童字体，不能作为本项目页面或字体选型的依据；只采纳其中适用的清晰层级与克制装饰原则。另行检索 Flutter 响应式布局及焦点遮挡，得到可用指导。以下色板、尺寸和伙伴方案属于项目设计判断，未宣称由数据库精确匹配得出。

## 3. 颜色与主题

默认跟随系统浅色/深色模式，首版不增加独立的云端主题偏好。组件使用下列语义角色，避免各页面自行选取相近颜色。深色模式单独配色，不对浅色页面直接反相。

| 语义角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| background | `#F5F7F2` | `#151C18` | 页面底色 |
| surface | `#FFFFFF` | `#1D2821` | 输入、弹层、需要独立层级的内容 |
| surface_alt | `#EAF0E8` | `#27382D` | 次级分区、本人话语、辅助内容 |
| primary | `#245C45` | `#A4D6B0` | 主要按钮、选中标识、链接、焦点环 |
| on_primary | `#FFFFFF` | `#113822` | 主要按钮文字与图标 |
| text | `#18251D` | `#E7EEE7` | 正文、标题、可靠转写 |
| text_secondary | `#526157` | `#BBC9BD` | 解释、时间、次级标签 |
| outline | `#718177` | `#84948A` | 输入边界、必要的控件轮廓 |
| divider | `#DCE5DC` | `#384B3D` | 非唯一识别依据的装饰分隔线 |
| danger | `#AF332D` | `#FFB4AB` | 删除、错误和结束按钮的危险层级 |
| on_danger | `#FFFFFF` | `#641B18` | danger 实心按钮上的文字 |
| danger_background | `#FCE9E7` | `#641B18` | 错误提示背景，搭配 danger 文字 |
| warning | `#805600` | `#F1C56A` | 尚未保存、待核对等需要注意的信息 |
| warning_background | `#FFF1D6` | `#3E3014` | 注意提示背景，搭配 warning 文字 |

品牌色不等于“正在录音”。是否采集、是否静音、是否断线都必须有文字和明确的控件状态；红色也不用于批量标记用户的英语表达。

正文、字幕、说明和按钮文字的项目目标统一为对比度至少 4.5:1；承载识别功能的控件边界和图标至少 3:1。divider 不能单独承担识别输入框、选中状态或焦点的责任。规则参考 [W3C 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)与[非文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

首次编制时已按不透明 sRGB 色值计算下列组合；显示值保留两位小数，判定使用未舍入数值。色值变化后重新计算并更新记录。

| 组合 | 浅色 | 深色 |
| --- | --- | --- |
| text / background | 14.74:1 | 14.68:1 |
| text_secondary / surface | 6.55:1 | 8.86:1 |
| text_secondary / surface_alt | 5.65:1 | 7.22:1 |
| on_primary / primary | 7.80:1 | 7.95:1 |
| outline / surface_alt | 3.55:1 | 3.90:1 |
| danger / danger_background | 5.38:1 | 7.23:1 |
| warning / warning_background | 5.79:1 | 7.90:1 |

这些计算不等于页面已经验收。未来加入透明度、遮罩、图片、按下态或真实字体后，应检查实际合成结果；不通过降低整块父组件透明度来制作可读文字的禁用态。

## 4. 字体与文字层级

首版建议采用平台系统无衬线字体，英文和中文分别使用可用的系统字形。iOS 可使用系统字体及中文回退，Android 使用系统无衬线及中文回退，Web 使用系统 sans-serif 回退；实际字形、字重和断行逐端验证。页面不依赖运行时从外部字体服务下载字体。若后续引入品牌字体，应确认中英覆盖、授权和打包体积后再更新规范。

下表是未叠加系统文字缩放时的建议基准，单位为 Flutter 逻辑像素。行高是排版目标，不是固定容器高度；大字号时允许增高和换行。

| 角色 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| page_title | 28 / 36 | 600 | 首页和独立页面标题 |
| section_title | 22 / 30 | 600 | 复盘分区、重点建议 |
| call_status | 20 / 28 | 600 | 正在听、连接中、已暂停 |
| subtitle_en | 18 / 28 | 400 | 当前英文字幕及复盘例句 |
| body | 16 / 26 | 400 | 中文解释、列表主内容、输入 |
| label | 16 / 24 | 600 | 按钮、字段标签、重要选项 |
| supporting | 14 / 22 | 400 | 日期、状态说明、辅助文字 |
| micro | 12 / 18 | 400 | 非关键元信息；不用于错误、权限或通话状态 |

英文保持正常大小写；标题靠字重和位置建立层级。语法反馈中的原句保持原样，建议句另起一行，不靠大量红线、删除线或全句高亮制造错误感。长英文、连续字符和中英混排需要自动换行，用户原话及关键解释不省略。

复盘阅读区最大宽度建议 680；英文段落尽量保持约 45–75 个字符的行长，中文以实际阅读效果调整，不通过字符数硬裁切。时间可使用等宽数字，但不把整套界面改成等宽字体。

## 5. 间距、形状与层级

| 角色 | 建议值 | 用途 |
| --- | --- | --- |
| space_1 / space_2 | 4 / 8 | 图标与文字、标签和说明 |
| space_3 / space_4 | 12 / 16 | 同组控件、列表项内部 |
| space_6 / space_8 | 24 / 32 | 分区之间、页面主要留白 |
| space_12 | 48 | 大区块和空态留白 |
| radius_small | 12 | 标签和小型分组 |
| radius_control | 16 | 按钮、输入框 |
| radius_surface | 20 | 话题、重点建议等独立容器 |
| radius_dialog | 24 | 对话框与底部面板 |

普通记录和设置使用分组、留白与分隔线；只有承载独立操作或更高层级时才使用卡片。首页自由聊天为一个主重点，话题为次级入口，不把所有项目包进同样大小的卡片。

正文表面通常不加阴影。弹层可采用轻量阴影，浅色参考黑色约 8% 不透明度、模糊 24、垂直偏移 8；深色优先通过表面和轮廓区分。弹层遮罩建议从约 40% 不透明度开始，实际检查背景隔离和文字可读性；不以玻璃模糊作为主阅读表面。

## 6. 组件规范

全平台可交互命中区域建议统一至少 48×48 逻辑像素，高于交互规格中的 44×44 项目下限；图标本体不必同样大。控件高度均为最小值，文字缩放后可以增高。

| 组件 | 建议呈现与尺寸 | 必备状态和语义 |
| --- | --- | --- |
| 主要按钮 | 最小高 56；primary / on_primary；窄屏充满所在内容区，宽屏通常不超过 320 | 默认、按下、焦点、等待、禁用；等待保留动作说明和单独取消入口 |
| 次级按钮 | 最小高 48；surface 与 outline，文字 text 或 primary | 按下、焦点、禁用；不能只有悬停才可发现 |
| 通话静音 | 24 图标加清楚文字，命中区至少 48 | “关闭麦克风 / 开启麦克风”表达动作；同时展示当前静音状态 |
| 我来说 | 可读文字与次级按钮层级 | 不要求按住；不可用时说明原因，不静默开麦 |
| 结束并复盘 | danger 层级，可用文字按钮或实心按钮；与静音至少间隔 16 | 直接执行交互规格中的明确结束流程；不能只有无标签红色圆点 |
| 文本输入 | 最小高 52；标签在上、说明和错误在下；必要轮廓使用 outline | 输入、焦点、错误、禁用；保留密码管理器和粘贴操作 |
| 话题入口 | 左对齐标题和一个交流目标，内边距 16–24 | 选中、按下、焦点；卡片若可点击则整个范围语义一致 |
| 历史列表项 | 默认最小高 80，内边距 16；日期、话题、状态可换行 | 载入、空、失败、已删除；普通练习与重练有文字标识 |
| 反馈条目 | 原句、建议表达、解释、类型、重练动作按固定顺序排列 | 零至三项；原句可定位；区分“纠错”与“表达更自然” |
| 状态提示 | 图标与可读说明；surface_alt / warning_background / danger_background 按语义使用 | 持续问题留在页面，不只出现一闪而过的提示 |
| 弹层 | 顶部明确标题、正文和有意义的动作名；窄屏底部面板、宽屏居中 | 焦点进入和返回正确；删除说明关联数量，恢复遵循交互规格 |

交互状态的共同要求：按下时立即有色彩或表面反馈；键盘焦点使用约 2 的 primary 轮廓和约 2 的外间距；悬停仅增强反馈。禁用控件有禁用语义、没有触发动作，原因在附近可读。加载状态不改变按钮宽度，也不让列表内容反复跳动。

图标首选同一套 Material 家族的 24 规格：未选中使用轮廓，选中可使用同家族填充并同时标记选择语义。微型辅助图标可用 20，突出状态可用 32。具体资源及导入路径在选定 Flutter SDK 后核对；不混用 React 图标包、系统 emoji 或来自多套家族的近似图形。

## 7. 伙伴与通话状态

伙伴的图形起点建议为“双层对话弧线”：两段柔和、略有错位的对话轮廓组成一个可识别标记，使用品牌色与浅表面层次。它可以具有少量表情，但不先绑定真人外教、性别、国籍、固定名字或写实口型。这是形象探索建议，尚未产出正式图形资产。

伙伴静态图形也应使页面成立。首页图形建议约 80–112；通话主图形约 144–192，均为正常字号下的参考范围。小窗口、大字号和字幕展开时优先缩小或隐藏装饰部分，保留状态和控制。后续实现可先使用 Flutter 原生绘制和动画；暂不把 Rive 或其他动画库列为必需依赖。

| 实际状态 | 文字与图形建议 | 必须保持的事实 |
| --- | --- | --- |
| 权限 / 本地设备准备 | “正在准备麦克风”，静态伙伴和设备说明 | 用户点开始后可能已打开本地设备，但尚未上送真实音轨；不能显示有效听取 |
| 建连 / 模型配置 | “正在连接”，轻量等待标记和取消入口 | 传输与模型均就绪后才进入听取；动画不伪装真实进度 |
| 等待用户且开麦 | “正在听你说”，安静的弧线状态 | 根据实际媒体状态显示；用户不说话时不播放虚构声量动画 |
| 用户有效发声 | “在听，请继续”，小幅信号变化 | 动画只能表示可观测信号，不将噪声直接认证为有效英语表达 |
| AI 生成 | “正在想怎么回应”，低干扰等待标记 | 用户仍可开口；没有确定进度就不显示百分比 |
| AI 实际播报 | “正在说”，图形随实际输出轻微变化 | 根据实际播放而非仅收到生成文本触发；开麦时仍允许自然插话 |
| 用户插话 | 停止旧输出动效，进入用户听取 | 先执行音频控制，再做视觉过渡；不能等动画结束才停播 |
| 静音 | 明确“麦克风已关闭”，稳定的静音标识 | AI 可以继续播报；静音与 AI 状态并行展示，不以一个图标覆盖全部状态 |
| 暂停 / 断线 | “练习已暂停 / 连接中断，已暂停”，停止信号动效 | 不继续显示正在收音；提供继续或结束保存 |
| 结束 / 保存 | “正在保存这次练习”，停止通话动效 | 本地音频已停止；上游费用未确认时显示用量待核对 |

听取、AI 生成、AI 播报、静音与连接状态不是一组互斥动画枚举。页面主文字选择最需要用户理解的状态，并补充并行状态，例如“正在说 · 麦克风已关闭”。屏幕阅读器只播报必要变化，不连续朗读动效或临时字幕。

## 8. 字幕、辅助与复盘的视觉区分

英文字幕、中文提示、按需翻译各有入口和可见状态；关闭一个不连带关闭另一个。字幕区域可以滚动，控制区不会被推到屏幕外；用户主动回看上文时不强行自动滚回底部，可提示有新内容。

| 内容 | 呈现规则 |
| --- | --- |
| 最终话语 | 标明本人 / AI，使用可靠文字；本人可用 surface_alt，AI 用 surface，避免只靠左右位置辨认角色 |
| 临时字幕 | 附“识别中”文字，使用 text_secondary；不得因为临时而降低到不可读的对比度 |
| AI 未播完文字 | 清楚标记“未播完”或对应未知状态，与已播放部分区分；不自动当作用户听过 |
| 英文开头 | 单独标识“表达提示”，和真实转写分区；不自动朗读 |
| 单句翻译 | 展开在所选话语下方，使用正文层级；生成失败说明原因并保留重试入口 |
| 纠错 | 原句原样保留；建议句和解释另列，以类型标签表达，不给整句盖红色底 |
| 可选润色 | 标记“表达更自然”，不显示错误图标、扣分或对错徽章 |

复盘开头是一个具体的下次建议，有依据时再展示做得好的点。表达建议数量可以为零，不为视觉饱满制造占位错误。无有效内容、没有可靠文字、反馈失败分别采用清楚的标题、解释和下一步动作，不展示模拟成绩或未经验证的能力图。

## 9. 响应式布局与平台适配

所有宽度均为逻辑像素，断点按当前窗口及组件的可用空间判断，不以手机/平板型号或横竖屏名称判断。以下是设计起点，未来根据真实内容、大字号和键盘场景调整。

| 窗口可用宽度 | 页面边距与导航 | 内容组织 |
| --- | --- | --- |
| 小于 600 | 两侧通常 20；小于 360 时 16；常规页底部三级导航 | 单列；通话控件允许两行；话题随空间变为单列或两列 |
| 600–1023 | 两侧 24；常规页可用 72 宽导航轨 | 主要内容限制宽度；通话默认仍可单列，避免过早挤压字幕 |
| 至少 1024 | 两侧 32；常规页建议 200 宽侧栏 | 主内容最大 1120；通话内容空间足够时伙伴与字幕两栏 |

通话、结束保存和复盘沿用交互规格，不显示一级导航。阅读区最大 680、登录表单最大 440。两栏通话仅在其实际内容区至少 840 宽且高度至少 600 时启用；较矮窗口优先减少装饰和垂直空白，必要内容允许滚动，不强行维持大图形。

固定控制区包含安全区和内容底部留白；列表、最后一段字幕、错误信息及键盘焦点均不能藏在其后。大字号或键盘使空间不足时，控制区可增高、换行并参与可达的滚动布局，结束操作仍可找到。页面不锁定竖屏，也不关闭浏览器缩放。

三端共享品牌色、组件语义和核心层级；开关、滚动、返回、文本选择、输入和页面转场遵循合适的平台习惯。宽屏保留相同功能顺序和返回路径，不新增另一套产品流程。平台适配依据 [Flutter 官方方法](https://docs.flutter.dev/ui/adaptive-responsive/general)。

## 10. 动效与触感

| 场景 | 建议时长 / 幅度 | 目的 |
| --- | --- | --- |
| 按下和释放 | 约 100 毫秒，色彩或表面反馈 | 立即确认触发，不移动其他内容 |
| 展开字幕、翻译和解释 | 约 180 毫秒 | 说明同一条内容的展开关系；可被下一次操作中断 |
| 弹层和页面衔接 | 约 220–280 毫秒，短距离位移 | 保持方向和入口关系，不阻塞返回 |
| 伙伴信号变化 | 小幅局部变化；实际音频有变化时更新 | 解释当前状态，不制造全屏呼吸、发光或持续漂浮 |

上述时间是视觉建议，不是业务等待时长或语音延迟目标。停止音频、静音、取消和结束立即进入相应业务处理，不等待动画。加载超时遵循技术策略，动画不自行无限重试请求。

尊重系统减少动态效果偏好：取消非必要循环、缩放和位移，以静态文字与图标表达状态，必要变化可直接完成。动画取消、快速点击、切主题和断线后，最终语义状态必须正确。触感仅作为可选增强，平台支持时再采用，不作为完成动作的唯一证据。
