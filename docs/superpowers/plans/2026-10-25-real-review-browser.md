**Architecture:** 当前Web release → loopback同源代理 → 标准create_app/qwen配置/真实后台runner → 独立PostgreSQL测试库。准备和封存用显式测试准入及固定英文，属于样本离线登记，不能当实际实时媒体。长期Key只在后端私有loader，不进入浏览器。

**Tech Stack:** 当前Flutter Web产物、FastAPI/HTTPX/PostgreSQL17与CUA实际浏览器；不预设应用改动或重跑无关全量。
