# 有界 PCM 分片播放实施计划

**目标：** 增加可复用的本地 PCM 分片排程与保守输出时钟估计，不开放正式语音。

**实现：** `apps/client/web/streaming_pcm_output.js` 维护单次响应的排程、节点和不可逆关闭；`apps/client/test/web/streaming_pcm_output_test.mjs` 使用受控 AudioContext 检验排程和异常。调用方独立管理 AudioContext 与业务生命周期。

1. 先写失败测试：两个分片连续排程、空隙与未播部分不计入，停止冻结估计并阻止迟到分片。
2. 实现 PCM16 小端转换、上限、顺序排程和可重复停止；测试无资源泄漏与排程错误。
3. 用测试覆盖无效时钟、倒退、上下文暂停、数据错误和缓冲过量时的保守行为；完成目标测试与已有 Node 检查。
4. 更新交接记录，明确该组件尚未接入供应商、不构成真实播放前缀或退出证明。实际 Web 浏览器播放和设备验证单独记录。
