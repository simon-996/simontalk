# 千问受限实时协议实施计划

**目标：** 将千问3.8配置确认和转写归一化接入既有协议回调，保留默认关闭与未知播放/退出状态。

**架构：** `qwen_guarded_protocol.dart` 实现一个单通道、单输入/回复的受限状态机，使用已有归一化器和控制器回调；测试显式构造，不改生产provider。

1. 先写配置确认、跨通道、重复和错误输入的失败测试，验证请求与回显匹配前不确认配置。
2. 写首轮识别与回复事件测试，将归一化事实送入真实投影；第二轮、意外回复和错配均停止，已生成文字不产生播放证据。
3. 测试正常drain时原回复的单次取消、最终尾部、清理和迟到事件；用已有控制器/替身传输验证通道及媒体生命周期。
4. 运行目标测试、Flutter分析/格式、相关全量和构建，记录任何不支持的供应商行为及默认关闭。
