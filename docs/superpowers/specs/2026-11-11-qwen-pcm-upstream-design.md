# 千问 PCM 上行单连接候选

在尚未注册到 API 的私有服务端组件中，接收已通过调用方鉴权、会话配置确认及资源所有权核验的 16 kHz PCM16 数据；本组件不证明上述前置条件、不开放接口、不管理数据库、不持有凭据。调用方必须先持久化并校验账号、练习、连接 epoch 和服务端上游配置；本模块不能替代准入。

初始静音，只接受显式逐次递增的静音代数。严格单调帧序号不重放，旧代或静音帧丢弃；未来代数、重复序号、错误长度、时间异常、超限或并发发送失败关闭连接。每帧固定 3200 字节，令牌桶持续 10 帧/秒、允许有限 6 帧突发；单连接最多 36000 帧。帧就地编码为规范 Base64、千问 `input_audio_buffer.append`，单次只允许一帧在途，不缓存或记录音频。真实连接有自己的有界发送/关闭行为。

静音或结束调用只阻止之后的交付，正在发送或已进入网络的数据无法撤回，因此不声称服务端接收到静音的精确边界；不因本地关闭认定供应商停止计费。所有异常返回固定代码，不包含音频或供应商数据。完整路径仍需 WebSocket 鉴权、代数控制协议、账户变更和端到端设备/供应商验证。
