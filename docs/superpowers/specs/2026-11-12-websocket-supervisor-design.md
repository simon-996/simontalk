# 服务端 WebSocket 启动主管（待实现）

启动主管只处理已持久化的一次 WebSocket claim，由服务器使用 claim 返回的唯一 attempt 打开上游；不创建路由、不开放准入、不从浏览器接收供应商地址/配置。练习快照中的固定难度与语速需在声明事务验证并绑定，服务器从该快照生成 QwenSessionGate，而非信任客户端提示或返回布尔值。

主管持有本次唯一 socket，在严格总截止内只接同一 socket 的 `session.created`、发送一次固定 `session.update`，再接并校验同 session/model 和完整关键设置的 `session.updated`。任何无效、超时、并发、取消、断开或数据库异常都禁止释放供业务使用，并尽力关闭本地 socket、记录该 claim 的 unknown；关闭不能证明供应商终止。网关本身拒绝重定向和日志，并对取消、迟到 socket、发送、关闭有界清理。只使用实际网关的有界连接实现，不将客户端 JSON 直接透传。

配置确认后，单独数据库事务必须先锁并复验原 Web 登录/用户，再锁本人练习和连接，核对 claim 指纹、原登录 ID、实例、epoch、状态、租约、供应商及难度/语速快照；只写 configuring（不冒充播放或完整练习），且提交成功后才能交给后续媒体生命周期。账号/配置失效或提交失败改走 unknown，直到独立终止核验。退出时在独立清理任务中有界关闭本地 socket 并记录 unknown；异步调用者取消时清理任务仍继续。数据库不可用、进程崩溃和网关取消未能完成仍由已有租约扫描保守处理。

必须用真实 PostgreSQL 和受控 fake socket 测成功、配置错、迟到、连接取消、账号撤销、租约过期、提交失败、退出/重入及并发单次打开；随后再考虑一次受预算控制的真实单连接配置验证。主管未接产品，真实麦克风、下游鉴权、音频交付、播放前缀、上下文和可信远端终止仍未解决。
