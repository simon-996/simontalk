# 千问 WebSocket 单次话轮与插话控制候选

服务端主管完成配置后，使用单连接状态机处理供应商语音/回复事件；仅从已认证的上游 socket 接收，不接收客户端伪造的供应商事件。目标是实现可审计的**单次受控回复**，不声称已实现自然多轮或完整上下文截断。事件按有界数量和内容摘要去重；ID、索引、文本长度/UTF-8 及事件顺序必须合法，重复一致事件不重复执行动作，冲突/未知格式失败关闭。

用户话轮按已验证的 speech_started → speech_stopped → committed → 非空最终转写认领，最多创建一次回复；`response.create` 仅由该最终转写触发，不接受客户端发送任意供应商命令。回复创建绑定 response ID，输出消息添加绑定 item ID，再由 QwenOutputAudioFilter 过滤音频增量。回复进行时，新的用户 speech_started 或同项非空转写增量可先到，先隔离当前已绑定回复音频、认领新用户项并最多发一次 response.cancel；同项迟到开始允许，无重复取消。若尚无可绑定回复而出现新话轮、已有用户项与不同新项冲突、无效转写、未授权新回复或非法状态，失败关闭。

回复完成只接受匹配 ID；普通状态仅 completed，插话竞争可 completed/cancelled。退休回复音频仍丢弃；插话新用户项可保存最终转写，但不能再生成回复，直到有准确已听前缀/上下文恢复的独立实现。动作是纯数据，由后续受控主管串行发送、转发及取消；业务状态机不能证明音频被听见、供应商停止或费用结清。未注册路由、不启用真实语音。
