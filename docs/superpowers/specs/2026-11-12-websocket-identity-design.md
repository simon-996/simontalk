# 浏览器 WebSocket 数据库身份核验候选

预检结果不是认证。本候选仅在调用者管理的数据库事务内验证 Web 登录 session 摘要、账号 UUID、到期、撤销和账号禁用。先按摘要及账号进行非锁定有效性检查，避免任意匿名预检直接锁住他人账号；再按既有顺序锁用户行、重新检查用户状态，最后锁认证会话行并按当前时刻重验有效性。返回用户和认证会话的 ID，不返回凭据或 ORM 对象；所有错误固定，不包含用户输入。

锁仅持续到调用者事务提交/回滚，阻止并发的账号停用/会话撤销在持久连接 claim 期间先提交；锁释放后撤销仍可发生，调用者必须在后续生命周期继续核验并及时停止媒体。长事务不得持锁进行上游 I/O，发送到供应商前必须另有明确持久连接所有权、epoch、同意及一次性 claim。组件不创建路由、不提交事务、不建立供应商连接，连接实际绑定和撤销监听另行实现。
