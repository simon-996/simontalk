# 来源练习关联重练列表

2026-10-23，持续开发授权内补当前交接下一单元。沿用既有Flutter视觉/交互与后端同级API，保留原工作分支；无后端/schema/依赖/媒体变更。

## 交互和范围

推荐从ordinary历史详情进入独立`/history/:sourceId/rehearsals`页面。相较详情内同时装载两种数据，它让列表有独立分页/错误/深链接，详情不会因翻页失败撤下；相较无限追加，它保持每次最多10条和明确返回操作。子详情不显示关联列表入口，避免把子当作新父；后端仍核验ordinary。

首次进入只GET同级列表，默认每页10条。展示子登记时间/结束登记时间和真实练习状态，可打开对应历史详情并沿既有入口看文字/复盘/目标。端点未提供难度、保存完整性、成绩或有效时长，列表不推测这些信息，也不把取消/准备算通话完成。空列表明确“还没有关联重练”，末页后来变空可返回上一页。

上一页/下一页只在明确点击时读取；成功后焦点与滚动回到本页结果标题，返回子详情保留列表页与滚动。网络翻页失败保留原页/页码及可重试动作，刷新清旧回第一页；游标失效或来源/身份失效撤下旧行并要求刷新/确认身份。没有自动轮询或写入，复盘失效不影响同级元数据读取。

## 数据和生命周期

严格有界不可变模型：envelope owner/parent/schema/source/limit，逐行同parent/kind=rehearsal/原item UUID，严格有时区实际日期和结束时间不早于登记；按(created_at,id)倒序、去重，next_before_id必须对应满页末项。保存本地游标的时间/ID边界，下一页不能重复或越过已确认边界。

每次读取用独立owner-bound HTTP fork、32KiB响应上限、总8秒与单调截止。构造/监听静默，单飞、dispose/账号切换取消并清空旧行，晚响应不能发布；旧行按钮回调重新核对当前owner与当前页成员后才导航。未设偏好可只读，恢复账号保持地址。

路由、Screen/provider、模型/仓库/控制器与纯View分开，复用AccountFrame/主题/时间格式及现有历史返回规则。Preview样例与正式数据隔离，320/200%字、横向、浅深/空/失败均验证。
