# 有界 PCM 分片播放设计

日期：2026-10-29。为未来受控 WebSocket 音频路径提供可复用的本地播放组件，不更改当前 WebRTC 通话、准入或上下文语义。

组件使用调用方提供的已运行 AudioContext，接收 8–48 kHz 单声道 PCM16 小端分片，按源采样率顺序安排 AudioBufferSourceNode。每片最多一秒、排程时距当前图时钟的终点最多10.05秒（包含50毫秒排程余量）、每实例最多256片；非法数据、状态异常、过量缓冲和排程失败均停止本轮并尽力释放节点。空分片不视为进展。组件监听上下文状态变更，观察到非running时停止本轮；调用方需在用户手势下创建并启动上下文，并负责在页面隐藏、设备变化、账号切换或连接失败时停止组件。异步状态通知不能保证观察到一切短暂切换。每个实例只对应一个响应，停止后不能重开或接收迟到数据。

转换和节点连接结束后才读取当前图时钟，按上一分片结束与当前图时钟加50毫秒两者的较晚值排程；这会增加起播等待，若供给过慢也可能产生空隙。调用start后再次读取图时钟，若时钟已越过计划起点则终止并将估计设为未知，避免将已经错过的排程时间算成输出；50毫秒是待实测的工程余量，不是设备延迟保证。即使该检查通过，线程时序、浏览器渲染与设备输出依然存在不确定性。

组件仅提供浏览器 `getOutputTimestamp()` 所报告的估计输出进度：必须处于 running、时钟值有限、单调且不超过音频图当前时间；按各分片安排起止累加并限制到已安排范围，空隙不计入。输出设备、采样时机、排程延迟与浏览器实现可能使估计不准确；任一校验失败返回未知，不能用未知值当作零或完成。停止时先采样，再停止和断开所有节点；释放抛错时冻结值改为未知，并继续释放其他节点。停止后保留该次估计或未知，迟到回调不能改变。该估计不证实用户听到，不证明词语边界或供应商音频时间戳准确。

此组件不接现有播放账本、上下文确认或供应商调用，不将 TTS 词段视为 Omni 音频的对齐。尚需真实浏览器、设备、输出切换、前后台和供应商映射验证；可信上游退出另行解决。
