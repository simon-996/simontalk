# Web 字体加载优化

日期：2026-10-16。按用户持续推进、不询问常规工程选择的指令执行；沿用既有视觉与本地资源要求。

## 目标与选择

当前引擎等待完整中文 TTF 后才显示首帧；文件为17,772,300字节。选择将原字体完整转换为WOFF2，保留全部Unicode映射、轮廓、度量、布局与可变字重，不做界面文字子集。初步样本7,781,888字节；最终数值以提交产物为准。

比较过的方案：只截取当前界面文字最小，但会遗漏任意姓名与以后真实转写；分块按需加载需要字符路由、字体注册和失败恢复，暂不增加这类维护成本；完整压缩保留现有覆盖，改动范围可控。文件减小不等于已经达到大陆网络启动指标，后续仍需真实网络测量。

## 加载与错误

WOFF2只作为Web平台asset，不声明为所有平台共同预加载字体。Web在运行应用前用FontLoader注册NotoSansSC；原生继续系统字体。Roboto继续作为引擎默认本地字体，避免Google服务隐式下载。加载中文字体期间保留HTML启动提示；网络失败向既有启动错误事件报告，显示中文错误与主动重载。未完成字体加载时不显示缺字的业务页面。

原始TTF和OFL留在仓库，中文原始TTF不打包到发布Web。工具固定字体处理依赖；校验源与产物的全部Unicode映射、字形轮廓/度量、布局、字重变化和许可证元数据，并设8MiB中文字体大小上限。CI校验而不重新进行高耗时压缩。

复核发现FontLoader可能吞掉字体解析失败，因此生成器同时输出长度和SHA-256元数据，Web在注册前验证实际响应；200 HTML、截断、损坏或旧缓存均进入启动重试。使用WebCrypto，运行入口为HTTPS或受信任loopback，不支持局域网普通HTTP。最终中文字体7,782,072字节，较源文件减少56.2%。

## 验收

构建产物不含中文TTF；中文WOFF2小于8MiB；源/产物内容校验通过；Flutter/启动测试和分析通过。真实浏览器正常显示中文并登录，日志没有字体解析或外部字体请求错误；临时本地故障服务器对WOFF2返回404时显示启动重试。真实手机、辅助技术和大陆网络仍单列未验收。

参考：[fontTools WOFF2读写](https://fonttools.readthedocs.io/en/latest/ttLib/woff2.html)、[Flutter字体格式](https://docs.flutter.dev/cookbook/design/fonts)。另核对当前SDK的SkiaFontCollection加载实现；桌面格式限制是采用Web专用加载的原因。
