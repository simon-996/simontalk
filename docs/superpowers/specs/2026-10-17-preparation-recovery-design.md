# 登记只读恢复与准备清理

日期：2026-10-17。按持续开发授权直接推进常规工程选择，不触及模型权限、付费连接、设备许可、推送或部署。

## 范围与方案

页面刷新会丢失内存中的创建键，现有连接扫描只有手动CLI，未建连的created练习没有自动释放路径。本批提供按本人身份读取当前占用的接口，以及API生命周期内运行的有界清理；客户端增加只读解析/仓库入口，不自动接管其他客户端或增加假练习页面。

比较方案：把创建键放浏览器持久缓存会增加身份/同步恢复复杂度；仅靠客户端退出取消不能保证送达；采用服务端当前登记查询和保守自动清理，保留所有行与幂等键，后续UI可显式处理真实占用。跨刷新重放原始未知请求及供应商终止仍不在本批。

## 当前登记查询

GET `/v1/practice-sessions/current`返回`practice`与`connection`，没有当前登记时均null；必须登录，沿用X-Account-ID绑定。单条SQL快照联查本人未终结练习及其最新连接，优先返回任何仍占用的连接，即使其父练习状态异常终结。连接只读，允许显示其他客户端实例，不续租、不分配epoch、不重新准入、不返回创建键或供应商凭证。

客户端PracticeRecovery解析同一练习归属/公开配置和代次关系，PracticeRepository.loadCurrentPreparation发GET；不自动调用begin、续租或取消。暂不挂载可见页面，无法把此入口称为完整刷新恢复体验。

## 清理规则

每批先执行现有连接租约扫描，再清理created练习。工程采用5分钟闲置资格：练习创建不晚于截止，并且没有仍占用、结束时间缺失、历史上游证据或最近5分钟终结的连接，才能标记cancelled/ended_at并记录`preparation_expired`。有过上游调用证据的练习不在自动准备清理范围；unknown继续占用。主动取消记录`cancelled_before_signalling`。

候选有界100条，按User→Practice加锁且skip_locked；拿锁后重新执行完整资格判断，不能覆盖刚建连接、续租或新代次。数据库增加准备原因字段和created清理索引。清理保留快照、行和原创建键，旧key重放终态，不重建练习。

## 调度和故障

API lifespan启动独立后台线程，每15秒执行一批；每进程各自调度，数据库锁和复查保证并发安全。使用独立连接池，停服发停止事件并有界等待，不在请求事件循环执行同步SQL。每批设置本地SQL/锁/事务超时；失败回滚并在下一轮重试，只记录固定错误消息，避免日志泄露连接信息。服务端进程退出期间不承诺执行清理；启动后重新处理积压。扫描不触及供应商，不代表媒体终止或费用硬上限。

保留手动连接CLI，新增`cleanup-preparations --limit`运行同一完整批次，供诊断/恢复。运行间隔是可配置工程参数，真实语音准入仍固定UnavailableAdmission。

## 验证

后端真实独立PostgreSQL测试：本人/他人/匿名/换账号、空当前/最新/异常父状态未知占用；TTL边界、近期终结保护、历史上游保护、锁后重查、并发扫描、键重放、后台循环失败恢复和lifespan停止。客户端HTTP替身测试GET头/形状/归属，不产生成功媒体证据。运行两端既有回归、Ruff/Alembic、客户端分析/格式/Web构建与字体校验；开发库只应用添加性迁移、重启API并只读检查，绝不注入假练习。
