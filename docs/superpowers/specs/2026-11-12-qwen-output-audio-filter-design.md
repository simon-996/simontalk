# 千问输出音频服务端身份过滤候选

未来由服务端主管持有 Qwen WebSocket 时，在经独立业务事件状态机确认的 response/item 上过滤 `response.audio.delta`，只向同一已授权下游提供音频所需字段。此单元不创建连接、不识别业务事件或证明响应已播放，也不直接开放路由。调用方必须先验证 `response.created` 和 `response.output_item.added` 等有序事件，显式绑定 response/item；未绑定不得交付音频。

每实例只允许一个活跃回复，显式退休后才可开启新回复，response/item ID 不复用，最多 64 个身份和每回复 256 个事件。合法增量须有唯一事件 ID、当前 response/item、零 output/content 索引、规范 Base64、非空偶数字节 PCM16，解码最多 48000 字节；多余供应商字段丢弃。退休回复的迟到分片不解码、不转发；错项、未知回复、重放、冲突/超限、畸形 JSON、异常类型失败关闭，错误不包含音频/模型文本。事件去重有界；不虚构播放前缀或将供应商完成事件视为设备已播完。

此过滤器与浏览器按回复隔离路由是两道独立边界。完整路径仍需认证下游、业务状态机、安全地触发 response.create/cancel、双向流控、取消后的上下文准确性和真实多轮/远端退出验证；此单元不开放正式语音。
