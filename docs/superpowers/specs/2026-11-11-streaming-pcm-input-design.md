# 有界浏览器 PCM 输入

为后续服务端持有 WebSocket 的候选提供浏览器输入部件，尚不接正式传输或开放准入。调用方在明确用户操作和协议/身份确认后提供已运行、采样率恰好 16 kHz 的 AudioContext 与一条已授权的 live 音轨；组件不调用 getUserMedia、不建立网络，且不拥有或停止调用方音轨和 AudioContext。调用方仍须负责立即停轨、关闭上下文、鉴权、账号变化和发送网络数据的范围。

AudioWorklet 使用浏览器音频图转换到 16 kHz 后的采样，每 1600 帧混合音轨通道、截幅并按 PCM16 小端生成 3200 字节，以 transferable 内存块交给调用方同步回调；不记录、保存或监听原始音频。工作节点输出全零并接零增益支路，只为驱动处理，不把输入送向扬声器。采样异常、处理失败或消费者不及时确认时停止部件并报告固定错误，最多允许三个待确认块，不静默丢弃正常语音。

初始默认静音，必须显式开启。每次静音切换递增代次并清空 worklet 部分分片；主线程立即更新代次并丢弃尚未到达的旧代次块，因此快速静音/恢复时旧音频不能重新交付。序号、代次、块长度及确认必须匹配；无效、重复或未来消息失败关闭。回调必须同步完成，异步回调不受支持。页面隐藏、离开、音轨终止、上下文不再 running、销毁或错误会同步封闭后续回调并断开节点；模块加载迟到不能重新启动。此组件的停止仅阻断本组件处理，不能冒充麦克风轨道已停止、服务端停止或上游结束。
