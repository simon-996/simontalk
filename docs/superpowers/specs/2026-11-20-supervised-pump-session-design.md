# 受主管约束的消息泵会话

增加内部单次会话函数，接收已核验的 `HandshakeIdentity`、持久 `WebSocketClaim` 与专属下游端口；不注册公开路由、不接收任意供应商指令。进入既有主管后创建消息泵，同时单独读取上游与下游；下游只能传受限 PCM 帧和控制。客户端 stop 可正常结束，断线、任何读取/发送错误或主管撤销须封闭两端并保守回写 unknown。

主管启动失败、会话取消、单侧异常及正常结束均关闭下游；会话不得以关闭完成证明上游退出。并发任务取消后若忽略取消，持有全局有界名额与下游归属直到其真正结束；下游发送任务在泵内部有独立追踪，不能只等读取循环结束。等候清理有界，迟到数据只可接触已关闭的消息泵，不能恢复或再建连。运行期间拒绝同一端口二次使用且不关闭现有会话；结束后调用方仍不得重新使用已关闭 socket。拒绝关闭的后台任务也有上限，极端容量耗尽无法启动关闭时由调用方保有并关闭该下游。错误固定且无文字、音频和凭据。主管继续负责持久身份、运行期复验和 unknown；本单元不自行认证浏览器，也不承诺上下文恢复或真实媒体验收。

受限控制明确验证 stop 后先标记本地停止意图：该动作会关闭上游，因此接收循环可能先因断线结束；此时有界等待停止控制处理结束，可返回本地 `stopped`，它不表示供应商已确认终止，也不排除停止同时发生的其他故障。没有经过验证的 stop 时，上游异常按固定错误关闭。
