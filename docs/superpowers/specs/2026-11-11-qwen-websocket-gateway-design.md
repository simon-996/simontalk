# 千问 WebSocket 受控连接候选

状态：单连接候选，不开放路由或准入。目标是在服务端持有真实上游 WebSocket，使后续有机会按回复区分音频并在客户端消失时释放本地持有的网络连接；这不证明供应商资源或计费已停止。

使用固定北京 workspace 地址与 `qwen3.8-omni-flash-realtime`、显式密钥和原配置四字段精确匹配；调用方必须先持久化唯一连接尝试并校验账号/练习/epoch，再建立候选。每个 attempt 对象最多一次连接，构造不发网络、不加载环境文件；不开代理、压缩或自动重试，并固定 `websockets==15.0.1` 后拒绝任何重定向。握手及发送有上限，消息仅接受有限 UTF-8 JSON 对象及非空事件类型。它是私有底层连接，不验证具体供应商业务事件或透传授权，调用方不得将任意客户端 JSON 无限制转发。

单连接只能有一个在途发送及一个在途接收；收到非法/二进制/超限数据或 I/O 失败时立即封闭并有界关闭。调用方取消读写时也开始本地关闭，不重用连接。关闭是幂等且可并发等待的单一任务，调用者中途取消不取消释放；超时尽力 abort 本地传输。结果只表示本机关闭尝试，不能解除 unknown 或宣称上游停费。服务端重启、建连期间丢回包、远端释放与账单均需现有持久占用和独立核验能力；不得用本连接类冒充这些能力。
