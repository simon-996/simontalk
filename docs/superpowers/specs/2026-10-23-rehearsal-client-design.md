# 一级重练客户端目标确认与独立准备

日期：2026-10-23，依据已确认D13/D20、既有重练契约和持续开发授权。沿用当前未提交功能分支和本项目Flutter规范，不新建脱离已有工程的工作树，不改依赖、模型开关或后端。

## 方案

推荐独立可深链接确认页，复用已验后端。相较在复盘内嵌创建，它能在刷新/返回时先重新核验来源，清晰分离只读与写入；相较直接启动媒体，它无需暂缺的模型权限，也不声称语音就绪。当前实现目标读取、独立准备登记、结果不明原请求确认及明确放弃；媒体、连接预留与改善评价留给后续真实语音单元。

普通复盘成功建议旁提供“练这一句”，仅在额外的本人练习元数据GET确认ordinary后显示；重练自身的反馈不再派生。跳`/practice/:sourceId/rehearse/:itemId`，只GET完整目标，展示完整来源原句、精确问题片段、建议/解释及必要安全前文；区分AI已播片段，不把建议当用户说过的话。已设置日常难度时可选三档本次难度，默认当前偏好，不更改全局偏好。未设日常难度仍可读取目标，但只提供“去设置难度”（既有/account→/setup），不显示本次选择或创建；设置后可从原复盘返回。后端即使收到override也要求全局偏好，客户端不绕过。默认不创建，明确“确认并准备”后固定target_hash/难度/key创建独立记录。

历史重练详情增加`/practice/:childId/rehearsal-target`只读入口，先读取本人子元数据，再读取固定目标并核对来源/item；不能从此入口创建下一层。源失效时撤下目标，不影响子本身独立记录。返回优先pop，否则回来源复盘/子详情；地址在账号恢复和未设难度时保留。

## 客户端边界

严格模型核对owner/URL/source kind/版本/UUID/hash/原句包含引用、UTF-8限额和安全前文结构。服务器验证完整目标摘要，客户端确认其原hash并核对创建回复的完整目标与刚确认对象一致，不另造摘要算法。模型不可变，无缓存到磁盘。独立owner-bound HTTP fork，每操作总8秒包含CSRF/多GET；单飞、单调截止、dispose/账号变化清正文并关闭请求，晚到不发布。

创建不自动重试，网络/超时/非法回复/未知5xx保留原目标、难度、key，只允许明确“确认上次准备请求”原样重放；不允许刷新替换未确认请求。确定拒绝后重新读取再确认，来源失效清除正文。已创建显示真实独立准备登记与实际难度，不显示已通话/已改善。明确放弃使用既有expected_epoch安全discard，无连接预留、信令或媒体。离页不启动新写入，尚未结束的准备在首页恢复面板继续可核对/清理；关闭页面不能声称撤销了服务器受理。
