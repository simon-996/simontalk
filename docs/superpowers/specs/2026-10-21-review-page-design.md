# 复盘入口、来源读取与结果阅读页

日期：2026-10-21。承接[复盘客户端](../../architecture/2026-10-21-review-client.md)与交互/视觉规格。持续工程授权允许常规可逆选择，复用当前功能分支和全部dirty；不提交/推送/部署、调用真实模型或恢复原生。

## 单元范围与选择

交付可真实访问的`/practice/:sessionId/review`，从现有恢复面板读取到的sealed摘要旁进入。URL只含练习UUID；页面重新通过本人GET completion确认来源，不把hash/账号/原话放入URL。只用路由extra会在刷新后丢目标，把全部原输入放入query又使来源过期且污染地址；采用本人来源读取+严格summary+既有ReviewTarget factory。

本批完整实现来源/任务状态与0–3条有效结果阅读；话轮跳转、完整对话、下次建议/优点总结、重练/删除和完整历史另需真实接口，不做假按钮或虚构内容。不得据此标记整个复盘/学习阶段完成。默认模型仍Unavailable。

## 来源协调与导航

新增ReviewPageController（命名可等义调整），构造零HTTP，持有原accountApi/accountId/sessionId。refresh先用独立fork GET `/v1/practice-sessions/{sid}/completion`，检查原账号/练习、source、origin UUID/client/epoch，再用现有PracticeCompletionSummary解析；ending只显示保存中，sealed才建立ReviewTarget并复用已有PracticeReviewClient。来源请求总8秒含取消/账号检查；随后任务纯读沿用既有client自己的8秒期限，两个有界阶段不伪装成单个8秒承诺。

同一已确认target复用client以保留不确定HTTP动作；来源重新读取时撤下旧显示但不换pending key。新target显式销毁旧client；新账号、dispose、来源缺失/失效或身份错误清除旧可见正文与动作，迟到请求不发后续调用。源读网络失败保留原client内的pending供来源重新确认后明确重放，失败期间不展示旧结果。任务层网络失败继续原client规则。外层操作单飞，刷新与写入不互相并行；结果、busy、error及可执行动作都由原账号getter核对后暴露。来源未确认时不能整理或重试。

初次打开页面主动纯读一次；不自动创建、模型重试或轮询。重新进入/刷新网址再次核对来源和现有任务。账号provider仅signedIn且原session UUID有效时建立controller，退出/变化及时释放。

路由允许已登录用户进入review；恢复账号或网络待恢复时保留合法review地址但不读取内容，显示相应账号等待/明确重连。未登录仍按现有规则去登录；不同账号访问同UUID由服务端本人门返回不可用。无效UUID不发HTTP。应用内push保留返回栈，直接地址也有“返回练习偏好”；不新增一级导航，不自动开麦或新建练习。恢复面板入口仅在本人sealed/来源无错误且非busy时可用，重新核对当前summary再跳转，ending/缺失/身份错误不开放。

## 状态与动作

| 实际状态 | 呈现与允许动作 |
| --- | --- |
| 来源/账号读取中 | 清楚说明正在核对/读取，不显示旧建议；返回可用 |
| 未登记保存 / ending | 尚未登记保存 / 文字仍在保存；仅刷新练习状态与返回 |
| 未建复盘 | 尚未整理建议；“整理表达建议”明确requestReview，“刷新复盘状态”仅GET |
| queued/running/retry_wait | 正在整理/稍后可刷新；仅纯读，不显示百分比或无限循环 |
| blocked | 表达建议暂不可用；刷新及既有canRetryGeneration允许的“重试整理”，无自动请求 |
| failed | 对话文字已保存，建议暂未生成；按canRetryGeneration开放明确重试，耗尽或outcome_unknown说明暂停重复生成/可刷新或联系维护者 |
| 不确定HTTP写入 | 提示上次请求尚未确认；“确认上次整理请求”仅retryPending，不能换成新的模型尝试 |
| 确定409冲突 | 先刷新当前状态；页面不绕过needsRead门 |
| no_evaluable_content | 没有可评价的用户表达；无生成重试，不说没有费用 |
| no_suggestions | 本次未整理出建议，不代表证明没有语言问题；显示有效空业务态 |
| succeeded | 展示实际1–3项，原话/建议/解释和纠错、表达更自然、拓展表达类型分明 |
| 读取失败 / 来源失效 / 账号变化 | 撤下旧建议，明确读取重试或重新确认账号/返回；不把失败当空建议 |

页面只显示实有日期和保存/缺口信息，不编造时长、难度、话题、分数、优点或下次建议。提示“建议基于本次识别文字”，有保存缺口时明确仅基于已保存部分。连接终止和用量不由复盘状态证明，提供返回原练习状态的说明，不宣称费用停止。

## 视觉、可访问性和预览

沿用现有主题/品牌，单列左对齐、阅读区max680，LayoutBuilder按可用空间设置16/24/32边距，SafeArea和整页可滚动，无遮住焦点的固定底栏。正文/原话可选择复制，长中英文原样换行，不裁切、不写死控件高度；正常与200%字号、320/375及横向宽矮窗口均可达。按钮至少48逻辑像素，Wrap或窄屏纵向组织；Material焦点/按下反馈，类型不能只靠颜色。

页标题及分区有heading语义，仅必要状态liveRegion，不反复播报整份建议；无装饰循环，尊重减少动画。可选择文本使用框架正常选择行为，不重现旧文本双击焦点抢占。light/dark独立验证主题对比。

新增纯视图+隔离预览文件，样例与真实连接分开；浅色三建议、深色320/200%字号及blocked/空态等preview仅用明确示例和空回调，不访问API、凭证或媒体。实际页面只消费本人controller，不使用预览数据兜底。

## 验证

先RED后实现：sealed入口/路由与刷新保留、来源GET精确身份及ending/404/非法形状、原账号/8秒/取消晚到/单飞，源读刷新隐藏旧内容与保留原pending，任务状态动作门及确定409；全部状态、三类item、长文本复制/正常200%字号、多尺寸/两主题/减少动画/键盘与语义。独立规格后质量审查。

root独立Flutter/Chrome/analyze/format、Node/Web/字体；真实浏览器用独立测试库/临时API：从恢复面板进入、默认blocked/0次、显式生成后有效三项、读取失败撤旧/恢复、B账号空内容或空建议及跨标签身份变化，均标明fixture性质。预览另起并实际查看浅深/字号。默认开发库不得写假练习；测试服务/浏览器标签/账号/邀请/凭证清理，默认API健康与17表数量核对，更新HANDOFF/规格/报告，不把真实语言质量或整阶段标为完成。

2026-10-22验收修补范围：浏览器push实际地址、编码前进历史/账号恢复和未设难度账号的阅读路径均补RED后修正；动作行移至稳定标题后、全部动态内容前，补刷新缩屏/回填后的焦点可见性回归。另因隔离来源暴露既有连接created_at(DB时钟)略晚于last_seen_at(应用时钟)，新连接三时间字段统一已有应用stamp；不改迁移或客户端严格门，额外独立测试库补API回归。均为既定可刷新阅读/可访问性与合法来源的可靠性修复，不增加产品取舍。
