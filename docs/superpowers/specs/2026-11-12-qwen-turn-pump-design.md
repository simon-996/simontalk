# 千问单次话轮服务端消息泵候选

内部主管配置完成后，消息泵唯一读取该上游连接的事件；不接收客户端伪造供应商事件。它组合 QwenTurnPolicy、QwenOutputAudioFilter、QwenSerializedSender 和 WebSocketPcmRelay：用户 PCM/静音只经受限入口；供应商事件先经有界状态机/身份过滤，仅将安全字段发给同一已授权下游；有效用户最终转写成功交付后，才经单写队列发送一次固定 `response.create`。

新用户插话时，策略在返回前退休当前回复音频；消息泵将带绑定 response ID 的隔离通知与固定 `response.cancel` 并行发起，任一失败均封闭上下游，不等待阻塞的下游通知才取消。通知成功后才转发插话事件；先前已在途的音频仍可能抵达，浏览器必须同步隔离相应回复，不声称其已听前缀。provider/client 的并发读取/控制冲突、错误、队列满、断线或超时须关闭、固定错误并交由主管记录 unknown。

单个下游输出有界并带截止，超时后只保留受上限约束的迟到任务直到结束，绑定的下游 socket 必须关闭且不可复用于其他账号/连接。输出不能吞吐无界 provider 队列或记录文字/音频。该泵是内部单次受控回复单元，不验证浏览器身份、不注册路由、不恢复被打断上下文、不证明实际听觉或供应商可信退出；正式语音准入保持关闭。
