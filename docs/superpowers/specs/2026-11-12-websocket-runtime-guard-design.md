# WebSocket 运行中身份与租约守护（待实现）

已配置上游不能只在启动时核验登录。服务端主管存活期间应定期在独立、有限时长的数据库事务中核验与 claim 完全相同的 Web 登录 session、用户、练习、连接、客户端实例、epoch、指纹、配置和未过期租约；只接受当前可继续工作的连接状态。撤销/过期/停用、租约失效、练习或连接范围改变、数据库不可用/超时，都立即关闭本地主持的 socket 并为该 claim 尝试保守 unknown/blocked 核验；不得报告上游已退出或撤销前发送的数据被收回。

检查间隔和数据库等待必须有上限，且每条连接不得并发堆积检查；数据库慢到超时即失败关闭。取消/后台清理与运行守护竞争时幂等，不产生第二次真实上游连接。现有 socket 收发层在关闭后丢弃迟到结果并禁止再次发送。定时检查是有延迟的最佳努力机制，不等于跨进程即时撤销；浏览器页面还必须自行在换号/隐藏时立刻停轨，上游已开始接收的数据无法撤回。进程暂停或消失仍需租约扫描和供应商侧终止证据；身份守护不能单独开放正式语音入口。
