# 浏览器 PCM 发送控制候选

为未来已完成服务端认证/claim/配置确认的单一浏览器 WebSocket 提供本地发送控制；不自行创建网络、不申请麦克风、不持有登录凭据。调用方将已打开且已授权 socket、已创建的 streaming PCM capture、同步释放实际媒体轨道的回调和固定错误回调交给本组件，capture 的同步音频回调须转发给本组件 `send`。调用方仍要在账号变化、权限丧失或主管失效时调用 stop，且确保只有服务端确认就绪之后才创建组件。

初始静音 epoch 0，停止前逐代递增。解除静音先按原连接发送严格 mode 控制，再开启 capture；静音时先同步关闭本地交付、调用 capture 静音，再发送 mode。每块音频仅在未静音时编码固定二进制头，序号全连接单调递增并通过同一 socket 按序发送；错误数据、socket 失效或 bufferedAmount 超限失败关闭。静音切换与发帧同步重入不能复活旧代；发送和停止竞争中已经交给浏览器的字节不能撤回。

停止、socket error/close、页面隐藏或离开时，立即将本组件置关闭、尽力静音/断开 capture、执行一次同步释放实际媒体轨道回调、注销事件监听并关闭 socket；正常停止可尽力发送 stop，缓冲已拥塞则不得继续追加数据。不能假定浏览器 WebSocket.close 丢弃已有缓冲，不能把本地静音/关闭当成供应商收到或停止计费。释放回调若失败仍保持失败封闭并通知调用方。具体页面绑定与真实设备体验仍须单独完成。
