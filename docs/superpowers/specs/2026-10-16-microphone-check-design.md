# Web 本机麦克风检查

日期：2026-10-16。按用户持续推进的授权实施，是阶段2到真实语音的前置能力，不代表AI对话已接入。

## 产品行为

在已完成初始设置的Web账号偏好页，保存设置下方增加“麦克风检查”。先说明“只在本机观察输入音量，不录音、不上传，最多30秒”；用户明确点“开始检查”才申请音频权限，不申请摄像头、不连接模型或上传接口。显示真实输入音量与剩余时间，不把噪声当作语音识别成功，不输出发音分数。

选择内嵌面板可保留未保存偏好、避免增加尚无真实练习能力的主页；独立检查页会增加导航状态，独立脚本则不能让正式应用用户复用。因此先实现正式设置中的完整小能力。

## 状态与生命周期

可选脚本准备中→待开始→等待浏览器授权→正在检查→已停止。脚本异步准备不阻塞账号页面；准备超过20秒显示未就绪说明，晚到就绪通知仍能启用面板，不触发权限请求。拒绝、无设备、设备占用、不安全入口、能力缺失分别说明可行的下一步；等待授权20秒后结束等待，允许取消。浏览器权限弹窗本身可能无法由页面撤销，提示未解决的许可仍可在浏览器处理；晚到的媒体立即停止，不重新打开面板。

用户停止、30秒到期、页面隐藏/退出、音频轨道结束、账号切换或组件销毁均关闭全部已取得轨道、音频上下文、采样timer和事件监听。回前台不自动采集。取消期间仍未返回的getUserMedia承诺保留晚到释放处理；过时回调不能覆盖新检查。

AudioContext失去running状态时也立即停止，采样前再次核查状态，不把中断期间分析器的冻结缓冲显示成实时音量。关闭前先移除状态监听，避免close事件递归清理。

使用Web Audio读取短时输入振幅，源节点只连分析器，不接扬声器。没有录音器、文件、持久存储或上传；不枚举/存储设备标识。权限只由用户操作触发，测试不代替用户接受麦克风许可。

## 工程与视觉

浏览器媒体实现放在本地`web/microphone_probe.js`，Dart条件适配器通过JS interop调用，原生未恢复时返回明确不支持。Dart控制器管理可见状态、授权超时、30秒限制和过时回调；浏览器实现负责实际轨道释放与页面隐藏。测试直接执行同一JS文件、注入明确的浏览器API替身验证竞态，并区分硬件验收。

沿用绿色、深浅色和现有表单宽度。状态含文字，音量条有语义名；停止/取消按钮始终可操作，不用颜色单独表达采集中。状态变化播报，不按每个音量采样抢读。窄屏和200%字号保持按钮可达。预览使用明确静态检查状态，绝不打开真实麦克风。

## 验收与边界

自动验证：点击前不申请；重复开始；权限拒绝；等待取消/超时后的晚到授权；新旧回调隔离；后台/退出/轨道结束；重复停止；分析器不接输出；全部轨道与上下文释放；窄屏深浅色大字号。

正式Web产物验证入口、静态/错误状态、原账号流程；真实设备输入、系统许可与浏览器采集指示灯需真人在受支持设备上执行。不会为获得证据自动接受用户的系统/浏览器麦克风许可，也不把替身音量视为真实音频证明。

参考：[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[MediaStreamTrack.stop](https://developer.mozilla.org/en-US/docs/Web/API/MediaStreamTrack/stop)。付费模型权限与预算尚不明确，当前不产生模型调用。
