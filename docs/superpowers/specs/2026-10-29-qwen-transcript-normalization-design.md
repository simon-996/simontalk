# 千问实时转写归一化

2026-10-29。为未来千问3.8实时语音适配器提供单连接内的转写归一化器；输入仅限同一已确认通道按顺序交付的事件。不会创建连接、发送配置或回复、触发付费请求、确认上游退出或开放语音准入。

依据[官方服务端事件](https://help.aliyun.com/zh/model-studio/server-events)，用户 `speech_started` 标识音频项，转写 delta 中 `text + stash` 是当前快照，completed 的 transcript 是最终结果；助手 response.created 先登记响应，output_item.added 绑定消息项，audio_transcript.delta 顺序拼接，done 的 transcript 是最终结果。只支持单个 message 输出项及 content_index/output_index 0；其他结构或缺少前置关联均拒绝并封闭本实例，不能猜测身份或次序。VAD多次相同项开始不创建新话轮；会话客户端不可跨连接复用，调用者须确保受保护通道、顺序与生命周期。

使用本机随机UUID映射供应商项及响应，首次用户开始和助手响应创建时按该通道事件顺序分配索引；turn与response UUID独立，供应商ID只作原连接内绑定。每个可用更新输出既有 `TurnStartedUpdate` / `TranscriptUpdate` 完整快照及递增revision，空最终文字允许；用户和助手分别以最终事件为权威，不根据delta推断最终识别。相同event_id的规范化已关注字段精确重放不再输出，冲突或无效字段失败；相同项最终结果的不同事件ID如果内容一致则幂等，不一致拒绝。回放只记录有限字段，条数与总字节受限，实例dispose清空正文与索引。禁止输出PlaybackUpdate，生成完成不代表声音已经播放。

单次文本最多8192 UTF-8字节、整实例最多256轮、事件最多1024且去重内容总计最多256KiB；拒绝无效Unicode、NUL、空/超长ID、错误索引、身份冲突、越界与final后的临时增量。错误为固定码、不含正文；失败后只可销毁，禁止继续产生更新。由未来适配器负责对原始JSON做入口大小限制及过滤其他事件；此归一化器不解释结束、配置、错误和音频事件，未知类型不得静默当作成功。

实际供应商与WebRTC事件时序、多个输出项、自动打断、最终转写尾部和上下文可控性尚未验证；需要真实媒体连接与上下文控制依据后，才能由默认关闭的协议工厂接入。模拟事件和公开文档不能代替真人设备验收或可信终止。
