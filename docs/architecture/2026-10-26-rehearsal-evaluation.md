# 一级重练改善评价

日期：2026-10-26。实现与验证状态见本轮开发报告及 `HANDOFF.md`。本契约落实[收尾与反馈契约第6节](2026-10-20-practice-completion-and-review-contract.md#6-一级重练评价与删除)，复用既有任务/租约/输入封存和结果存储，不增加媒体准入。

## 数据与依据

仅对已封存的一级重练生成。任务仍绑定子练习的输入版本、练习摘要、复盘摘要和生成政策；另核验创建时冻结的普通父反馈与目标摘要。来源被删除、修改或失效时，撤下依赖旧目标的结果，子本身的历史保留。

`review_result_v1` 增加可选 `rehearsal_evaluation`。普通练习及旧存量不含该键，保持旧结构；新重练有可评价文字时必须生成它。评价与普通建议均纳入结果 hash；有评价而零建议仍为 `succeeded`，不会显示成“没有改善”。旧空建议结果继续为 `no_suggestions`，不能据此推断目标是否达到。

存量兼容不等于旧客户端能读取新扩展：现有客户端采用严格字段校验，启用新重练生成前须先配套发布支持该扩展的客户端。当前没有执行部署，日常供应商配置仍默认关闭。新增提示和Schema改变网关指纹，已绑定旧指纹的未完成任务按既有配置变化规则暂停，已保存结果不因指纹改变而失效。

```json
{
  "schema_version": "rehearsal_evaluation_v1",
  "target_hash": "服务器核验的目标摘要",
  "intent": {
    "status": "conveyed",
    "explanation": "本次表达保留了目标意思。",
    "evidence": [{
      "source_connection_id": "子练习连接UUID",
      "source_turn_id": "子练习用户话轮UUID",
      "revision": 1,
      "exact_quote": "Yesterday I went to the park."
    }]
  },
  "target_issue": {
    "status": "demonstrated",
    "explanation": "本次正确使用了过去式。",
    "evidence": [{
      "source_connection_id": "子练习连接UUID",
      "source_turn_id": "子练习用户话轮UUID",
      "revision": 1,
      "exact_quote": "went"
    }]
  }
}
```

| 维度 | 状态 | 展示含义 |
| --- | --- | --- |
| 意思表达 | `conveyed` | 本次表达了目标意思，允许不同说法 |
| 意思表达 | `changed` | 本次改变了关键意思或事实 |
| 意思表达 | `insufficient_evidence` | 本次文字不足以判断 |
| 目标问题 | `demonstrated` | 本次表达达到目标，不宣称长期掌握 |
| 目标问题 | `still_present` | 本次仍出现目标问题 |
| 目标问题 | `not_demonstrated` | 本次没有出现能检查目标的表达，不等同失败或掌握 |
| 目标问题 | `insufficient_evidence` | 识别或上下文证据不足 |

每轴有非空简短解释；确定结论必须引用本次子练习中有评价资格的用户原话及准确版本。不能引用父练习、AI回复或安全前文冒充本次表现。引用须为原句精确片段；识别疑点不能被模型擅自纠正或转成发音判断。没有可评价文字仍为既有 `no_evaluable_content`，不调用模型。

## 模型与可靠性

使用现有文字复盘网关和 durable worker；提交后不会由页面自动重复调用。上游只得到目标所需文字、类型与安全前文，当前表达使用局部整数索引；UUID、账号及业务摘要留在本地映射。模型返回两轴及引用索引，服务端补入目标摘要并与子输入再次核验。普通提示和严格输出规则继续有效。

来源在领取、实际外调前、结果写入前及读取时重新核对。删除或失效后的迟到结果不能恢复内容；未知模型调用和配置变化仍沿用既有保守重试规则。用量缺失为未知，不能记零。引用结构正确只证明有可核验出处，语言质量仍需实际固定样本和后续真实语音抽查。

## 客户端

本人复盘页在已有建议区域显示两个独立维度、解释及本次引文。无评价的旧结果不补造评价；重练结果不提供二级派生入口。账号变化、刷新/读取失败、在途离页继续使用原页面的正文撤下与动作范围门。证据引文可选择，查看全文复用“查看已保存文字”。本次不为评价创造新的定位协议。
