# 受限 PCM 消息处理候选

新增未注册的服务端消息处理单元：仅接收固定格式的二进制 PCM 帧、严格的静音代数控制和停止控制，默认静音，不接受供应商命令。按版本/代数/序号解码后交现有 QwenPcmInput；旧代或静音帧丢弃，错误、重放、并发或取消失败关闭。所有到达帧包括被丢弃的旧帧都受速率和总量限制，控制消息也有限速与数量上限。停止与异步静音变更重叠时不能重新开放处理；所有错误使用固定码。

新增 17 项离线测试，包含白名单控制、PCM 格式、代数/重放、超速/总量、错误 JSON、同时发送、取消和静音切换期间关闭；后一项先失败再修复。含双端格式、Qwen 上行/连接和配置门共 102 项 Python 目标通过；Node Web 全量 107 项、Ruff、148 文件格式及依赖锁通过。未使用真实音频、网络或供应商。

该单元尚未接收 ASGI WebSocket 消息，也不认证用户或保证客户端同步停轨；未来路由必须先完成来源、CSRF、持久账号/连接绑定及供应商配置，并限制双向缓冲。停止本地连接不能证明远端退出或撤回在途音频，正式语音准入继续关闭。
