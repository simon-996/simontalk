# 浏览器 WebSocket 一次性首消息凭据

ApiClient 新增仅供 Web 使用的短时握手凭据对象：复用同账号共享的 CSRF 获取，并在获取前后及消费时检查当前账号和调用方生命周期；仅接受规范小写 UUID 与后端允许的 CSRF 格式。凭据只可消费一次，消费前切号/客户端关闭/生命周期取消会永久失效；对象字符串不含 token。消费结果只含首消息 `authenticate`、账号 UUID 和 CSRF，不创建 socket、不放入 URL，也不代替服务器的数据库会话与连接核验。

目标新增 6 项加既有 CSRF 测试共 10 项通过（初版接口缺失先失败）；Flutter 全量 1559 项通过、10 项原有专用跳过，静态分析无问题，Web release 构建通过。无真实 WebSocket 认证、麦克风或供应商调用。

业务层尚未将凭据交给正式传输；调用方必须在消费后立即发送并持续监听换号，服务器仍须执行来源/CSRF、数据库身份和 claim 校验，不能把本地对象当成认证成功。正式语音准入关闭。
