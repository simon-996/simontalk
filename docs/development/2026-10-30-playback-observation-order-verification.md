# Web 播放观察顺序修复

2026-10-30。检查产品浏览器传输和控制器时发现，旧 `play()` 请求的超时或权限拒绝可能晚于新的播放结果，把已经开始播放的状态覆盖成等待或受阻。Flutter 控制器的异步恢复调用也可能在较新播放观察或较新的恢复请求之后返回同类错误并覆盖状态。

先写浏览器替身测试，两种旧等待/权限拒绝覆盖较新 `playing` 的情况均按预期失败；先写控制器测试，较新的 `playing` 被迟到等待结果覆盖的情况按预期失败。之后为浏览器播放调用/`playing` 事件和控制器恢复调用/播放观察分别增加代次保护；有效的迟到权限拒绝仍会报告，非权限错误即使迟到仍关闭媒体。回调重入时也不把旧等待结果作为当前结果返回。

这些测试执行生产 JavaScript 与真实 Flutter 控制器，但浏览器、传输和服务均为替身；它们验证状态时序，不证明实际听见、播放内容对齐或模型会话已集成。本轮没有供应商请求或麦克风采集。正式语音入口依然关闭；产品媒体控制器真实端到端、多轮、插话及上游可信退出仍需继续验证。
