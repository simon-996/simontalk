# 浏览器 PCM 二进制帧候选

定义并实现未接网络的二进制编码/解码：固定 13 字节头（版本、静音代数、序号）和 3200 字节 PCM，字段大小端与范围见[规格](../superpowers/specs/2026-11-12-websocket-pcm-wire-design.md)。浏览器生成独立副本，服务端严格检查长度、版本和安全整数序号；解码结果不在 repr 中显示 PCM。现有 QwenPcmInput 的离线组合测试接收解码结果，仍按自己的静音、序号和速率门处理。

JS 目标 2 项、Python 目标 10 项通过；两端核对同一固定字节向量与畸形输入。Edge 回环页面用本地合成字节实测 3213 字节、固定头和独立副本均通过，见[结果](evidence/2026-11-12-pcm-wire-browser.json)和[页面](evidence/2026-11-12-pcm-wire-browser.html)。Node Web 全量 107 项与 Flutter Web release 构建通过，脚本源码与构建产物 SHA-256 一致；Ruff、146 文件格式和依赖锁通过。未使用麦克风、网络语音或模型。

这只是未来授权 WebSocket 的帧格式，尚无公开路由、浏览器发送或跨网络音频。序号/静音控制、缓冲、账号/设备生命周期及真实供应商联通仍需接入验证；正式语音准入关闭。
