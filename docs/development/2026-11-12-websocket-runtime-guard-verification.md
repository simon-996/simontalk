# WebSocket 运行期身份与租约守护

服务端内部主管在配置成功后，每隔 1 秒开始一次数据库复验；单次等待最多 2 秒，不同时发起下一次。复验同一 Web 登录 session、账号、练习、连接、实例、epoch、指纹、服务端配置、难度/语速快照和租约；认证撤销、租约到期、状态不再允许、数据库错误或超时都会触发本地 socket 关闭，并沿用服务端 claim 写入 unknown 和 blocked 终止核验。退出时停止守护，清理任务与守护并发时共享一次清理；守护先完成而上下文仍未退出时仍保留该活动名额。

隔离 PostgreSQL 加本地假 socket 验证运行中撤销和租约过期能关闭连接；两项测试在未实现守护时先超时失败，随后通过。数据库复验阻塞测试确认超时后关闭且不反复堆积检查，迟到的只读复验不能复活连接。与安全握手、声明、原 WebRTC 信令、终止和删除等目标共 229 项通过；Ruff、144 文件格式与依赖锁检查通过。本轮未连接真实供应商或麦克风。之前完整后端及真实备份恢复为 1325 项零跳过；该全量在新增运行期守护之前。

1 秒间隔与 2 秒数据库等待是内部配置，不构成硬实时保证：系统调度、挂起、断网、数据库和上游关闭都可能延迟。已在途数据无法撤回；浏览器仍须在换号/隐藏时立即停轨。持有者不退出上下文时虽然本地 socket 已关闭，其活动名额仍会被保守占用。没有部署或注册公开 WebSocket 路由，真实音频、自然插话、端到端会后闭环和可独立核验的上游终止仍缺，正式语音准入关闭。
