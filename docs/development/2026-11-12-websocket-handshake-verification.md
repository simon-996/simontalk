# 浏览器 WebSocket 首消息预检

2026-11-12。新增未注册到 API 的无副作用预检：限定一个符合精确允许列表且格式有效的 Origin、无查询串/Authorization/子协议、一个 Cookie 头，session/CSRF cookie 严格格式且不可重复。首消息只能是 1024 字节以内 UTF-8 JSON，禁止重复字段，仅接受 authenticate、规范 UUID 和匹配 Cookie 的 CSRF。成功仅返回账号 UUID 和 session 摘要，repr 不显示摘要；失败为固定错误，不包含 cookie、令牌或消息。

针对预检的 22 项离线用例先见缺失模块失败，并补测无效 Origin 即使被错误配置到允许列表仍必须拒绝、子协议中不得夹带令牌；与 PCM 上下行/供应商连接目标共 67 项通过。非数据库后端回归 520 项通过、733 项因测试数据库不可用而跳过；Ruff、134 文件格式和锁检查通过。本轮没有真实用户媒体或模型调用。

这是语法、来源和 CSRF 预检，**不是身份认证，也不能防重放或证明账号/练习/连接所有权**。下一步必须在数据库检查登录是否撤销/过期、账号是否禁用和 ID 是否一致，以一致的锁顺序确认持久练习与唯一连接尝试；也需实时处理账号撤销、网络断线和上游未知。首消息应有单独截止，消息大小必须在 ASGI/代理层限制；生产 HTTPS、代理和日志不得泄露凭据。当前没有注册 WebSocket 路由，正式语音准入仍关闭。
