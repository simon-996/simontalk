# 2026-11-11 浏览器 PCM 输入基础能力验证

新增独立输入组件及 AudioWorklet：调用方传入其已获授权的单条活动音轨、处于运行状态且采样率严格为 16 kHz 的 AudioContext；输出 100 ms、3200 字节 PCM16 小端单声道，初始化默认静音。组件不申请麦克风、不关闭调用方音轨或 AudioContext，也不连接网络。

静音切换立即更新主线程门并增加代数，旧代消息即使迟到也不交付；采样线程丢弃部分帧。最多三个未确认帧，超限、异常帧、设备结束、页面隐藏/退出、上下文暂停或处理器故障均停止交付。初始化加载最多等待 5 秒，停止后迟到的模块不会接线；同步停止与创建/接线重入不重新接通节点。消费回调必须同步，所有权方仍须自行停止真实麦克风及网络。

## 验证

- Node 定向 10 项通过（先复现异步模块取消和同步接线重入两种问题，再修正）；浏览器 Web 全量 105 项通过。
- Edge 157.0.4341.46，回环页面内使用振荡器和 MediaStreamDestination，输出支路零增益；实际 16 kHz，首次解除静音收 6 帧，静音后仍 6 帧，再开启后 10 帧，停止后仍 10 帧；每帧 3200 字节，无错误。页面关闭音轨和 AudioContext。未使用物理麦克风、模型或保存音频。见[结果](evidence/2026-11-11-pcm-input-browser.json)和[实验页](evidence/2026-11-11-pcm-input-browser.html)。
- Flutter Web release 构建通过，两个输入脚本构建产物 SHA-256 与证据中源码一致。该脚本仅打包，并未由产品页面加载或接入真实供应商。

## 限制

合成源成功并不验证真实麦克风许可、浏览器/设备兼容或人声品质，不证明对话、供应商接收、模型回复、旧播放上下文、真实远端退出或计费。上行要接入产品还须完成账号及已持久化连接身份绑定、服务器转发/限流、错误与中断、媒体所有权清理和端到端测试。正式语音准入仍关闭。
