# WebRTC传输层验证

日期：2026-10-17。当前本地功能分支；不调用供应商、不申请物理麦克风权限、不推送、不部署。

## 实现范围

生产脚本`web/realtime_transport.js`直接使用浏览器WebRTC；Flutter通过`lib/features/realtime/`桥接。创建对象/加载脚本没有权限、网络或播放器副作用。接口尚未接到练习页面，后端真实准入仍固定关闭。

- `start`只调用一次注入的信令，不自动重试；等待完整ICE、Answer、实际连接和事件通道。客户端和服务端创建的通道都处理，以通道ID明确发送目标。
- 采集到的音轨在供应商适配器调用`activate`前不挂载。该调用需真实配置确认，传输层不猜测模型事件；静音是用户控制，播放不会自动关闭上行。
- 20秒授权、30秒协商/信令/连接、20秒配置确认等待；事件64KiB、缓冲256KiB、SDP256KiB、每实例最多8个通道。
- 结束、后台/pagehide、设备/连接/控制通道失效均关闭本地采集、连接、通道及播放器，取消信令、移除监听器和定时器；晚到授权/SDP/播放结果不恢复资源。
- 音轨挂载、传输连接和实际播放分别观察。自动播放限制可显式恢复；无数据的播放请求5秒返回等待，晚到许可拒绝仍可观察。播放器错误释放资源。

本地关闭只产生`local_closed`，不产生供应商终止成功或零费用记录。没有实现供应商取消、输出缓冲清空、播放上下文截断、最终转写和计量；没有宣称自然插话已通过。

## 自动验证

先添加测试观察缺少脚本/桥接失败，再实现；可选脚本失败测试先观察不到通知而失败。

最终`node --test test/web/*_test.mjs` **51项通过**：原26项、22项传输检查、1项实际编译Dart→JS后执行的桥接检查、2项可选脚本失败检查。传输检查使用明确浏览器API替身执行生产脚本；桥接检查使用明确JS接口替身验证异步SDP、字符串事件、播放错误与取消回调，未把替身结果写成硬件验收。

`flutter test` **41项通过**，`flutter analyze`无问题，Dart格式通过。Web release构建通过；静态脚本随正式产物分发。字体完整性与本地Roboto校验通过。后端未修改，本轮没有把此前62项后端结果写成新运行。

复核发现并修复一项P2：音轨挂载后等待首次`audio.play()`，无可播放数据时激活Future可能不返回，配置定时器却已取消。增加待定播放测试先观察失败，随后分开激活和播放；停止能结清待定操作，显式恢复播放有界。补充超时后晚到拒绝测试，先复现通知丢失，再保持原播放Promise的错误观察。最终独立复核22项传输检查通过，无剩余P1/P2。

## 真实浏览器本地回环

在Codex应用内浏览器执行`test/web/realtime_loopback.html`。该工具仅在开发服务提供，不进入`build/web`。它执行同一生产脚本，以合成静音流替代物理麦克风输入，其余使用两个真实RTCPeerConnection。

页面最终显示通过：ICE/SDP、双端创建的DataChannel、收到测试配置确认后才上行合成音轨、静音/恢复、音轨ended与幂等关闭/信令取消。测试同时协商远端无音轨的sendrecv transceiver，仍通过；该浏览器没有复现待定play问题，不把替身复现说成浏览器复现。没有真实下行声音播放证据。

复现命令在仓库根目录运行：

```sh
python3 -m http.server 7358 --bind 127.0.0.1 --directory apps/client
```

打开`http://127.0.0.1:7358/test/web/realtime_loopback.html`，点击“运行本地检查”。工具明确标注合成输入；不申请设备权限、不调用模型、不录音。结束时恢复被替换的采集方法并关闭测试上下文，超时后的任务不能新建资源。临时本地测试服务在本轮结束前关闭。

最终Web release在本地7357正式产物服务重载后，实际显示完整登录表单及无障碍heading。生产源码、发布文件与真实HTTP返回的传输脚本字节一致；发布HTML包含可选脚本入口，回环工具没有进入发布目录。本轮没有输入账号凭证或接受浏览器许可。
