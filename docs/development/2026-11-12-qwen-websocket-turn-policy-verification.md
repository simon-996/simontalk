# 千问 WebSocket 单次话轮策略候选

新增未接网络的单次话轮状态机：先认领用户开始、停止、提交和非空最终转写，才产生一次回复请求动作；回复 ID 和输出 item 经确认后才接音频，由服务端输出过滤器限定身份/格式。已有回复时，新用户开始或同项非空转写增量可先到；先退休旧音频并输出隔离动作，最多发一次取消动作，允许同项迟到开始与最终转写，但不再发第二次回复。回复完成仅接受匹配 ID 和允许状态；精确重复事件不重复动作，冲突/越界失败关闭。转发事件仅保留必要字段，状态/错误对象不输出转写或 PCM。

新增 14 项离线用例，覆盖单次回复、早到转写插话、旧音频隔离、重复/冲突、非法顺序、空转写和错身份；插话最终转写换事件 ID 复发先发现可重复转发，现已封闭。含服务端输出过滤、配置与 PCM 等共 101 项目标通过；Ruff、152 文件格式与依赖锁通过。未连供应商、麦克风或产品路由。

这是纯状态/动作，还需由唯一服务器连接串行协调音频上行、回复创建、取消和下游投递。它不恢复被打断回复的准确已听前缀或多轮上下文，也不证明人耳、真实设备、供应商远端退出或费用。正式语音准入继续关闭。
