# 真实复盘在本人Web页面的验收

2026-10-25，使用现有Flutter Web release、桌面IAB、同源loopback代理和独立PostgreSQL17库。标准`create_app`显式配置`review_provider=qwen`，生命周期runner调用真实`qwen3.8-flash`；没有替换应用网关或响应正文。应用源码、schema、依赖和私有`.env`没有变化。

## 输入与范围

两个合成账号通过真实API注册。本人两份封存样本分别为`Yesterday I go to the park.` / `I usually take the bus to work.`和`I have been living here for three years.`；另一账号有独立样本。准备、封存使用测试准入和固定英文，连接未真正打开媒体。数据库中的closed不能当作供应商退出证据；本轮没有麦克风、语音上传或实际通话。

初始复盘输入、任务、尝试、结果及模型请求均为0。现有Web产物晚于全部客户端lib源码，直接复用，没有重建或把历史自动测试写成本轮重跑。产物摘要和脱敏记录见[证据](evidence/2026-10-25-real-review-browser.json)。

## 实际页面结果

| 操作 | 观察与证据 |
| --- | --- |
| 登录本人，从记录/详情进入复盘 | 显示“尚未整理建议”；进入页面只读，没有模型请求 |
| 明确点击“整理表达建议” | 两个样本各创建一次任务，均由正常后台runner处理；页面排队态提示显式刷新，不自动轮询 |
| 错误句生成后刷新 | 真实结果引用`Yesterday I go`，建议`Yesterday I went`，中文解释过去时；未对正确的bus句生成建议。人工逐项检查通过，仅代表这份样本 |
| 点击“定位到对话” | [原话页](screenshots/browser-real-review-quote.png)高亮第一段，显示精确引用与完整保存句子；第二段仍为原保存文字 |
| 返回、重新加载及重开正例 | 仍显示原结果；没有额外生成POST或模型请求 |
| 一次复盘GET被代理拒绝503 | [旧建议撤下](screenshots/browser-real-review-read-failure.png)，显示读取失败且登录保留；再次明确刷新恢复原结果，仍仅一次正例模型请求 |
| 正确句明确生成并刷新 | [有效空结果](screenshots/browser-real-review-empty.png)，文案明确不等于证明表达没有语言问题；数据库为`no_suggestions`、空items |
| 第二标签退出本人并登录另一账号，再操作旧标签 | 真实completion GET409，[旧建议和来源正文清除](screenshots/browser-real-review-account-changed.png)，提示重新确认账号 |
| 换号后重新加载旧地址 | 真实completion GET404，[复盘不可用](screenshots/browser-real-review-other-owner.png)，无旧建议；另一账号历史仅一条自己的记录 |
