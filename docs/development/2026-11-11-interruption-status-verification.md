# 受控插话后的页面状态

2026-11-11（Asia/Shanghai）。针对当前千问受限候选：未知播放边界的回复隔离后，旧协议不再发送新回复，而此前通话页只显示“已暂停播放”，没有解释下一步或麦克风状态。

## 变更

- 媒体协调器从现有未知回复隔离和活动状态推导 `interruptionNeedsEnd`；不是推断上游是否终止，也不是新供应商能力。只有该状态时，通话页提示“对话已中断，暂时无法继续”，说明说完当前句后结束；未静音时明确提示麦克风仍开启。
- 用户仍可立即静音及结束；一旦静音，页面和控制器都拒绝在该受限状态下重新开启麦克风，避免旧回调重新上送音频。正常通话的静音切换不变。进入收尾后移除中断提示，沿用既有立即停止媒体和有界等待最后一句的流程。
- 隔离状态不展示普通播放恢复按钮；空字幕状态不再提示可以继续自然插话。既有 `StatusMessage` 使用 live region。可用宽度相对文字尺寸较小时，中断状态的静音和结束按钮纵向排列。
- 添加独立中断预览。深色、320 逻辑像素、200% 字号的 Flutter 测试渲染图已人工查看，使用预览示例对话，见[渲染图](evidence/2026-11-11-interrupted-call-preview-dark-320.png)；这不是实际通话或真机截图。

## 验证

真实页面配媒体协调器与测试替身的回归先因缺少中断提示而失败；修补后覆盖显示状态、隐藏旧提示/恢复播放、用户静音、控制器拒绝重新开麦以及进入收尾。视图测试覆盖普通暂停区别、320 宽/200% 字号下纵向按钮和无布局异常；新增预览可以在不连接服务时渲染。页面/视图/预览及原有中断协调器目标测试通过。

最终页面/视图/预览及协调器目标测试 81 项通过；Flutter 全量 1553 项通过、10 项专用 skip；静态分析无问题、7 个 Dart 文件格式通过、Node 83 项通过，产品 Web release 构建通过（33.5 秒，未执行 Wasm dry-run），构建传输脚本与源码 SHA-256 一致。单独 Flutter 测试渲染已查看，未启动 Widget Previewer 或真实浏览器通话。最初一次临时渲染测试因在测试内异步读取字体而卡住，中止后改为测试前加载字体，重新通过并生成上述图；临时测试已删除。

## 外部能力与边界

本轮仅查阅公开文档，没有调用模型、物理麦克风或业务数据库。阿里云当前 [WebRTC 连接说明](https://www.alibabacloud.com/help/en/model-studio/realtime-webrtc-access)介绍停止本地采集、关闭 DataChannel/PeerConnection 与清理播放器；[模型说明](https://help.aliyun.com/zh/model-studio/realtime)也要求 WebRTC 停止媒体并关闭连接。这些说明本身没有提供本项目所需的客户端消失/SDP 回包丢失后的独立远端终态核验依据，因此仍不能由本地关闭推断上游释放或停费。

本次没有实现插话后音轨安全恢复、新一轮回复、可信远端退出或设备真人验收，正式语音准入仍关闭。下一步继续验证安全恢复、对话上下文和上游退出，再完成真实多轮及设备验收。
