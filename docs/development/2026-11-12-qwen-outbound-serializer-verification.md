# 千问单连接上行串行调度候选

新增未注册的单写入者调度器，接收服务端生成的固定 PCM append、`response.create` 和 `response.cancel`；严格检查消息键、规范 Base64 和 3200 字节帧，拒绝任意其他命令。网络发送最多一个在途，等待队列限定音频 3 帧、控制 2 条；已有在途发送不可抢占，排队控制优先于排队音频。同类按顺序。队列溢出、取消、无效消息或网络错误时封闭并关闭，本地错误不含原始消息；实际底层连接自身限制超时和迟到 I/O。

11 项自身离线测试，覆盖并发优先顺序、队列满、坏命令、取消、幂等关闭、上游错误及与真实 PCM 适配器和单次话轮状态机组合；与音频过滤、配置、网关和 wire 共 142 项 Python 目标通过，Ruff/154 文件格式/锁通过。使用假连接，没有供应商或音频设备调用。

此单元尚未接真实主管/下游路由，不能自行决定回复是否合法；由话轮策略控制每次创建/取消权限。控制优先不撤回已在途音频，断开也不证明上游停止或费用结清。正式语音准入保持关闭。
