# WebSocket 数据库身份核验与完整后端回归

2026-11-12。新增未注册的事务内身份核验：对浏览器预检的 session 摘要与账号先检查有效性，避免匿名输入直接锁他人；然后依次锁定用户和登录会话并复验禁用、平台、撤销、到期与账号归属，只返回两个 ID，不提交事务或访问供应商。等待认证行锁期间可能跨过到期时间，因此取得锁后使用 PostgreSQL 当前时钟再次检查。

隔离 PostgreSQL 17.11 使用临时目录 `/tmp/simontalk-postgres-test-nov12`、回环端口 15429、专属 `simontalk_agent_isolated_test` 和临时随机口令；与现有开发库及其端口分离。PostgreSQL 和依赖从 Homebrew bottle 解压到临时目录，为运行未安装版本临时创建两条指向临时目录的 Homebrew 路径链接，测试完成后应删除本轮创建的链接并停止临时库；没有安装或升级现有软件。真实备份/恢复测试使用临时包装器运行同版 pg_dump/pg_restore，禁止静默跳过。

10 项真实数据库测试通过，覆盖有效登录、撤销/过期、平台、账号禁用、跨账号/错误摘要、事务期间撤销阻塞、初检后并发撤销及等待锁期间到期。特意撤掉“获得锁后复验”时，过期竞争测试失败；恢复后连接及 PCM 相关目标共 77 项通过。完整后端在该独立库和真实备份/恢复工具下 **1263 项通过、零跳过**（146.39 秒）。Ruff、格式、锁检查通过；本批无用户音频或供应商调用。

身份锁只持续到调用方事务结束；连接启动和运行期间仍必须绑定并复验同一认证会话、练习与连接、租约及服务端配置，还需处理账号撤销和客户端离线。此功能不创建 WebSocket 路由、不进行持久连接声明、不开放正式语音，不证明供应商资源释放或费用结清。
