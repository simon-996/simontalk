# 服务端 WebSocket 启动主管候选

新增默认未注册的服务端主管：只接受已经事务声明的 claim 和实际 Qwen 单次连接 attempt。声明时从持久练习快照固定三个难度、normal/slow 语速，拒绝无效快照。主管先复验登录、本人练习/连接、实例、epoch、租约和供应商配置；在唯一 socket 上依次接 `session.created`、发送固定 `session.update`、校验同 session 的 `session.updated`；再次做数据库身份和配置复验，提交 configuring 后才进入内部连接上下文。它不建立下游路由，不允许据此开放正式语音。

上下文退出、配置错误、注销、超时或取消时，本地连接关闭并尝试记录 unknown；未知仍要求独立终止核验。清理对调用方等待最多 7 秒；后台任务及活动名额继续保留至实际清理结束，最多允许 128 个活动/待清理实例。数据库持续不可用或进程退出仍可能使清理未完成，依赖租约扫描保守处理。原网关继续限制单次打开、网络截止、迟到 socket 清理及禁重定向；不保存音频或供应商消息。

隔离 PostgreSQL + 受控本地 socket 测试覆盖成功配置/退出、配置回显不符、会话启动前和回显前撤销、重复主管、取消、退出时异常、迟到 socket、清理阻塞、畸形 claim，以及取消后的迟到数据库确认不得复活连接。测试只构造假事件，不触及真实供应商、音频或模型费用。清理阻塞超时门和畸形 claim 各先复现失败再修复；与身份、声明、终止、原 WebRTC、删除及 PCM 等目标共 225 项通过，另有迟到数据库确认测试单独通过。最新完整后端及真实备份恢复为 1325 项通过、零跳过（151.27 秒）。

配置门的完整供应商回显尚未真实实测；上下文内部连接供未来服务端代码使用，不能把客户端 JSON 原样转发。运行中账号撤销监听、真实用户音频、会后完整闭环、自然插话、精准播放前缀和可独立核验的远端退出仍缺；因此正式入口仍关闭。
