# 正式练习页真实千问 WebSocket 联测

2026-11-25（Asia/Shanghai）。本地 `main` 为 `1abc6a8`，联测使用工作区已有的正式练习页改动。编译 `test/web/practice_session_browser_entry.dart`，在 Chrome 158.0.8127.37 和隔离 PostgreSQL 17.11 上运行正式 `SimonTalkApp`。本机回环 API 只为临时账号注入现有语音准入策略和真实千问网关，模型为北京地域 `qwen3.8-omni-flash-realtime`。启动链路先做一次仅配置的真实连接，当前配置校验接受回显，未发送音频或请求回复。

浏览器测试驱动用 Web Audio 媒体流输入两段本机合成的英语，页面仍走 AudioWorklet、同源 WebSocket、真实后端和千问。Chrome 输出静音，记录音源开始、自然结束、主动停止及协议事件时序。每次只开一条上游连接，无自动重试，普通通话最多两次回复请求，插话测试最多一次。只记录事件类型、计数、状态和时间，未保留识别正文、模型回复内容或响应音频。

| 双轮对话 | 第一轮 12 秒观测窗内收到识别、23 片音频及回复终态，但未观察到播放结算；测试退出后练习为 `interrupted`。单次复验延长观测窗并记录 Web Audio 时序，收到两次正常终态，57 个音源全部自然结束，两个回复均发送播放结算。首个终态到首个结算约 9.33 秒。页面结束后可查看保存情况，数据库按顺序保存四条转写，完成记录为 `sealed`，媒体轨道为 `ended`。 |

四次语音连接共对应五次明确的回复请求。四次返回用量的回复合计 3,576 Token，生成期取消未返回用量，实际账单未核。三次通过的正式页场景均观察到上游 WebSocket 关闭码 `1000`，首轮超时试验记录 `1006`。通过的场景中，本地终止状态仍为 `unknown`，插话场景的终止核验为 `blocked`、0 次。关闭码仅记录传输结果，远端会话释放及停费仍待核验。
