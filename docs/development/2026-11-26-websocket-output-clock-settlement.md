# 浏览器输出结算与千问新连接的语音上下文验证

2026-11-26（Asia/Shanghai）。正式练习页仍在隔离配置验证，语音准入保持关闭。

## 浏览器播放结算

网络侧回复完成后，浏览器先等该回复所有 Web Audio 音源自然结束。若支持 `AudioContext.getOutputTimestamp()`，在输出时钟追上最后一片音频的排程终点后才发送 `settled` 并放行下一轮。等待每 25 毫秒采样，最多 1 秒。输出时钟倒退、数据非法、超时或等待时音频上下文暂停均进入 `playback_failed`，停止采集和播放，省略 `settled`。浏览器原本没有该接口时沿用音源自然结束，回复没有 PCM 时直接结算。插话隔离、结束或离开会取消等待。

输出时间先于音频图时间采样，避免渲染线程推进时把有效样本当作超前。采样后重新核对截止时间，避免长查询跨过 1 秒仍错误放行。结算帧只用于轮次推进，持久播放证据仍为 `unknown`。浏览器时间无法定位用户听到的单词，也无法确认物理扬声器实际出声。[Web Audio 输出时钟](https://www.w3.org/TR/webaudio-1.0/#dom-audiocontext-getoutputtimestamp)

最终 Node 139 项、Chrome 与隔离 PostgreSQL 17 的媒体联测 8 项通过。双轮场景在真实 Web Audio 音源自然结束后，暂时把输出时钟固定在 0，确认至少采样两次、90 毫秒内没有结算，然后恢复 Chrome 原始采样，正常继续下一轮并保存四条转写。浏览器联测使用合成输入和千问替身。测试入口与正式 Web 包均重新构建，两份媒体脚本和源码逐字节一致，正式包字体保留 30,890 个映射。Python 联测文件 Ruff 检查及格式通过。

## 千问新连接

使用服务端 `QwenWebSocketGateway`、生产用 `QwenSessionGate` 和北京地域 `qwen3.8-omni-flash-realtime`，隔离实验通过工作空间域名 IPv6 建立一次新连接。供应商确认一条明确标为学习者资料的用户项，内容为选词 `MAPLE`。随后发送 147,200 字节合成 PCM（含尾部静音），最终识别为 “Which word did I choose earlier? Give just that word, please.”；手动请求一次回复，返回 49,920 字节 PCM、最终转写 `MAPLE` 和 `completed`。供应商回报 794 Token（输入 777、输出 17），本地 WebSocket 关闭码为 `1000`。实际账单和远端资源释放待核对。本次只用合成语音。

这次观测表明单个新连接在收到明确的学习者资料后可以用语音回答。正式通话的插话路径仍采用受控中断。千问公开事件表未列出可确认的部分截断事件，同连接删除已获确认但曾在随后的回答中复述旧内容。助手转写也曾在首片音频之前全部到达。现有证据无法安全截取已听文字或确认旧连接结束，暂不在插话后自动建连。[客户端事件](https://help.aliyun.com/zh/model-studio/client-events) · [服务端事件](https://help.aliyun.com/zh/model-studio/server-events) · [既有上下文对照实验](2026-10-28-qwen-context-vad-verification.md)

## 日常话题和一级重练的语音抽样

沿用同一供应商网关、生产配置校验、入门难度和正常语速。每个合成样本建立一次独立连接，通过服务端 VAD 和真实 ASR 得到最终转写后手动请求一次声音回复。四个日常话题使用内置配置，一级重练使用固定原话和目标建议。

| 样本 | 回复内容 | 回报 Token |
| --- | --- | ---: |
| 周末计划 | 回应周六去公园的安排，提到放松和呼吸新鲜空气 | 856 |
| 饮食 | 回应番茄汤让人想家的原因 | 853 |
| 兴趣爱好 | 回应最近学画鸟，继续问在练习画哪种鸟 | 877 |
| 旅行 | 回应春天去京都的计划，提到樱花 | 846 |
| 一级重练，自然改述 | 回应放学后和朋友打篮球，沿同一话题继续交流 | 986 |
| 一级重练，只请求改述 | 语音没有提到篮球，回复从重练配置给出 “I really enjoy playing basketball with my friends.” | 941 |

六次均收到最终语音转写、非空 PCM 和 `completed`，本地 WebSocket 关闭码均为 `1000`。四个日常话题首轮都贴合输入，其中一例主动追问。一级重练第二个样本证明这一次回答确实使用了冻结的练习内容。样本量只支持本次定性观察，多轮引导和物理设备仍待验。加上新连接上下文试验，本轮共七次连接、七次回复、供应商回报 6,153 Token，无自动重试。账单及远端释放状态待核对。
