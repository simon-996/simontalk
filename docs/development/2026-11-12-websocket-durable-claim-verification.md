# WebSocket 持久连接声明候选

2026-11-12。新增默认未注册的服务端单次声明。先事务内验证并锁定 Web 登录/用户，再锁本人练习和连接，核对 client instance、epoch、准备状态、租约及服务端准入/供应商配置。网关的 `attempt` 只进行本地配置检查；在返回它之前，再次核验登录有效性及租约，原子持久化指纹、启动时间、negotiating 和 termination unknown 并提交。提交失败时不返回 attempt，不调用上游。

为不破坏现有备份及删除归档修订，本单元不修改 schema：沿用历史字段 `offer_digest` 保存服务端构造的带类型/版本前缀及全部身份的 SHA-256 尝试指纹。既有 WebRTC SDP 路径始终以 `v=0` 开头，不能直接构造同一原文；该指纹也让既有未知退出占用、租约清理及终止核验能够识别已尝试启动。它不包含音频、密钥或 SDP，也不表示上游已经收到请求。具体边界见[设计](../superpowers/specs/2026-11-12-websocket-durable-claim-design.md)。

隔离 PostgreSQL 上新增 14 项检查覆盖并发只提交一次、重放、WebRTC 双向冲突、提交失败、账号/实例/epoch/准入/配置失效、登录在校验期间过期、租约过期和既有 blocked 终止证据。含原信令/终止/放弃准备及身份共 88 项通过。完整后端和真实备份恢复共 **1277 项通过、零跳过**（146.46 秒）；Ruff、格式和锁检查通过。本轮不触发供应商连接或使用麦克风。

仍未将声明接到公开 WebSocket，也没有结果回写、运行时会话撤销、真实音频传输、自然插话或可信上游终止。原正式语音准入保持关闭；不能把数据库标记为真实通话成功或供应商计费已停止。
