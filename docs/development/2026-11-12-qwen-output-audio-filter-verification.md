# 千问输出音频服务端过滤候选

新增未接路由的严格输出过滤器：由可信业务状态机显式绑定 response/item，仅接相同身份、零索引、唯一事件、规范 Base64、非空偶数字节及最大 48000 字节 PCM 的 `response.audio.delta`，只返回播放器需要的字段。一个回复显式退休后才能绑定下一个；退休回复的迟到音频不解码、不转发。回复/item 不复用，身份及事件数有界；错项、未知回复、重放、格式/容量异常失败关闭，不输出原音频或额外供应商字段。

新增 15 项离线测试，覆盖绑定/退休/迟到、错身份、重放、规范 Base64、PCM 边界、非整数索引和身份/帧容量；与上游配置、连接、PCM 输入及双端 wire 等共 117 项 Python 目标通过，Ruff、150 文件格式和依赖锁通过。本轮未连接真实供应商或输出设备。

过滤器依赖未来的已认证会话和业务状态机提供可信 response/item，并非服务端已经完成回复调度；也不证明实际扬声器播放、被听见的前缀、上下文裁剪或上游停止。正式语音准入关闭。
