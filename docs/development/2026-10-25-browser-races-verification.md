## 独立环境

真实应用内浏览器→7357测试代理→默认供应商关闭的API8001→专属`simontalk_races_20261025_d9e31_test`。A含普通来源+2子+11旧记录，B含普通来源+11旧记录，两来源各23段测试文字/1项测试反馈；种子使用已有fixture和明确模拟关闭状态，A另设置unknown用于占用观察。这不是实际口语、可信终止或语言质量证据。测试代理只延迟特定响应，不改变生产路由/业务响应。

## 实测结果

| 场景 | 实际结果 |
| --- | --- |
| scope409 | 浏览器原展示父+2子共3条；独立移动测试凭证经实际API删除一子，未轮换浏览器CSRF。原确认DELETE409/deletion_scope_changed，父/另一子保留；页面撤旧范围并要求重读，明确重读展示2条 |
| 父删除回包迟到 | 重读后确认2条，API已成功但代理延迟10秒；页面进入结果不明，晚到200没有自动当成功。只读GET凭据确认并返回历史，unknown仍保留。此轮定位器首次等待提前超时，没有用它计算精确8秒 |
| 单条删除计时 | 另选B的一条无正文旧记录，成功回包同样延迟10秒；页面在**8.076秒**进入结果不明，随后GET凭据确认。迟到200不改变当前历史路由，网络没有自动再DELETE |
| 翻页截止 | B已读第1–16段，下一页响应延迟10秒；**8.082秒**显示翻页失败并保留原页，未展示晚到第17–23段 |
| 刷新总截止 | completion与saved-transcript各延迟5秒；**8.241秒**结束，原正文已清除。晚到正文到达后仍为失败，明确刷新后正常读取。证明两步共用截止，不是各等8秒 |
| 在途离页 | 文字下一页延迟10秒，立即返回详情；响应迟到后URL仍为详情，焦点仍在查看文字按钮，没有跳回或抢焦点 |
| 保存情况总截止 | 详情与completion各延迟5秒；按实际页面文案重复计时得到**8.132秒**，失败不保留旧保存结论，晚到后仍失败；明确重读恢复记录已保存 |

计时包含浏览器点击和定位器观察延迟，是本机个例，不是性能分位数或严格计时精度承诺。定位器单次等待约3秒的工具上限通过有界连续等待处理；首轮保存情况使用错误预期文案而等待失败，未当产品问题。返回记录按钮处于滚动视口外时，DOM指针点击没有导航；滚到顶部后实际点击可返回，不据此改生产代码。
