# 浏览器媒体入口与断开收尾

在一次性 PostgreSQL 17.11 和回环 Uvicorn 上，以独立配置目录启动真实 Chrome 157.0.8103.80。页面取得测试 Cookie，用浏览器 WebSocket 发送账号与 CSRF 首消息，等待 ready 后发送开启输入的控制和一帧 3200 字节的合成 PCM。上游替身收到 append 后发回带测试 item 的语音事件。正常停止与撤销登录两次分别观察到一次 ready、一次匹配事件、一次上游打开和一次关闭。浏览器分别收到 1000 和 1011。两次均查询到数据库连接状态 unknown、终止核验 blocked、尝试次数为零。

另有 11 个 ASGI 情形覆盖首消息超时、过长、二进制或提前关闭，错误 Origin 的升级前拒绝，持有真实连接行锁时浏览器断开或抢先发送媒体，上游配置阻塞时断开，运行期输入队列溢出，以及声明已提交后容量拒绝和迟到回写保留名额。被锁住的事务稍后提交时，原声明最终记 unknown，供应商替身打开次数为零。等待配置时断开则关闭已经启动的本地上游。回环服务将传输层消息和队列分别限制在 4096 字节与 4 条。

含两项 Chrome 测试在内，浏览器入口、数据库身份与声明、主管、消息泵、PCM 和网关等 250 项定向测试全部通过（18.75 秒）。Ruff 检查通过，后端 src 与 tests 共 147 个文件格式通过。测试容器已自动移除，端口 57092 已释放。重跑浏览器用例时，将 SIMONTALK_TEST_BROWSER 指向 Chromium 系浏览器可执行文件，SIMONTALK_TEST_DATABASE_URL 指向专属的可清空测试库，再运行 services/api/tests/test_browser_media_loopback.py。

本次验证使用测试页面、合成账号和本地供应商替身。Flutter 通话页接入、物理麦克风、真实供应商的上下文与退出证据仍待验证。标准应用继续保持正式语音准入关闭。
