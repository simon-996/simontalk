# 通话内英文开头和逐句翻译

2026-11-25（Asia/Shanghai）

## 已接入的行为

- 「给我一个英文开头」从本次连接的难度、话题和最多两条已登记的最终用户话轮生成一条英文提示。用户可以在说第一句前主动请求。已显示但仍待上传确认的本人话轮会暂缓发起请求。
- 「逐句翻译」打开当前通话的最终英文话轮列表，翻译用户选定的原句。服务端绑定原连接、话轮 ID 和精确修订。尚未登记、已修订或来自其他连接的话轮无法生成。未选中的新话轮不会使已选译文失效。
- 结果以独立文本呈现，可以与英文字幕同时显示。关闭字幕或中文提示后仍可主动求助。提示、译文和失败文案均独立于转写、语音播放及复盘资格。结束、账号变化、连接代次变化或目标修订后撤下旧文字。

## 持久化与恢复

上下文 GET 只返回版本摘要和同输入的既有请求 ID，已有结果重新打开会走只读验证。POST 在账号锁内校验原连接和输入摘要，按练习、类型、输入版本去重。两种能力使用各自的千问指令和配置指纹。后台在发出前复验原登录、连接、任务截止和服务关闭状态。结果提交前再核对版本、截止及账号状态。已知未派发或明确可重试的失败可由用户重试，未知调用不补发。

实际派发按独立辅助尝试记录供应商输入/输出 Token，缺失保留未知。删除练习清除提示和译文，保留无正文用量。本人用量和本次练习用量在显式请求辅助分项后返回该项，旧客户端使用原契约。迁移 `7cfa81b28360` 和 `19d7a3ec0b51` 保留原练习和英文开头记录；含实际数据时相应降级受到保护。
